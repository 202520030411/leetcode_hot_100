# 练习区（第二遍手写用）

这个目录放**我自己从零写的代码**，和仓库里原有的 100 题题解分开。

## 怎么用

```
① 打开 ../学习笔记/刷题进度表.md，按优先级挑一道
② 关掉笔记，在这里新建 编号-题名.py，从零写
③ 跑 python3 编号-题名.py 验证
④ 最后才打开笔记对照，看漏了什么
```

**第 ④ 步才看笔记** —— 先写完再对照，否则等于抄一遍。

## 命名规则

和笔记对应：`01-两数之和.py` ↔ `../学习笔记/01-两数之和.md`

## 自查清单（写完逐条过，摘自 [我的高频错误](../学习笔记/我的高频错误.md)）

```
□ 1. return 的类型和函数签名的 -> 对得上吗？
□ 2. 每个 while 的条件变量，循环体里真的被改了吗？
□ 3. 每个 x[i]：我这步要的是位置还是值？
□ 4. range 的起止对吗？j 该从 i 还是 i+1 开始？
```
