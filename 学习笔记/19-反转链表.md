# 19 反转链表（Reverse Linked List）

> 链表 · 简单 · **必考，链表第一题** · https://leetcode.cn/problems/reverse-linked-list/
> 🎞 https://claude.ai/artifact/8uEt9GBR552GDAaz9eRuHM

## 核心思路一句话

**三个指针 `prev / cur / nxt`，逐个把箭头掉头；改 `next` 之前必须先存住原来的 `next`。**

## 题目

| | |
|---|---|
| 给你 | 链表头节点 `head` |
| 返回 | 反转后的**新头节点** |

```
输入: 1 → 2 → 3 → 4 → 5 → None
输出: 5 → 4 → 3 → 2 → 1 → None
     ↑ 原来的尾巴变成了新的头
```

## 链表基础（先确认这个）

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val       # 盒子里的值
        self.next = next     # 指向下一个盒子（到头了是 None）
```

```
┌───┬──┐   ┌───┬──┐   ┌───┬──────┐
│ 1 │ ●─┼──▶│ 2 │ ●─┼──▶│ 3 │ None │
└───┴──┘   └───┴──┘   └───┴──────┘
  值  指路牌
```

**数组是连号座位（能跳着取），链表是一串盒子（只能顺着找）。**
**遍历模板：** `cur = head` / `while cur:` / `cur = cur.next`

## 思路：逐个掉头

```
初始:   None    1 → 2 → 3 → None
        prev   cur

第1步: 把 1 的箭头指向 prev(None)
        None ← 1    2 → 3 → None
              prev  cur

第2步: 把 2 的箭头指向 prev(1)
        None ← 1 ← 2    3 → None
                  prev  cur

cur 走到 None → 退出，prev 就是新头
```

## 代码

```python
class Solution:
    def reverseList(self, head: ListNode) -> ListNode:
        prev = None                 # 新链表的"前一个"，初始 None（将来的尾巴）
        cur = head
        while cur:
            nxt = cur.next          # ① 先存住下一个！
            cur.next = prev         # ② 掉头
            prev = cur              # ③ prev 前进
            cur = nxt               # ④ cur 前进
        return prev                 # prev 是新头（cur 此时是 None）
```

## ★ 三个关键细节（面试必问）

**① 为什么必须先存 `nxt`？**

```python
cur.next = prev      # 这一行把"指向下一个"的指路牌改掉了
cur = cur.next       # ← 没提前存，这里拿到的是 prev（往回走），后半条链丢了
```

> **链表题铁律：改一个节点的 `next` 之前，先把原来的 `next` 存下来。**

**② 为什么返回 `prev` 不是 `cur`？** 退出条件是 `cur == None`，此时 `prev` 停在最后一个真实节点上。

**③ 为什么 `prev` 初始是 `None`？** 原来的头反转后变成尾巴，尾巴必须指向 `None`。

## 复杂度

时间 **O(n)**，空间 **O(1)**。

**递归版（面试作为补充提一句）：**

```python
def reverseList(self, head):
    if not head or not head.next:
        return head
    new_head = self.reverseList(head.next)   # 先把后面整条反转好
    head.next.next = head                    # 让后一个指回自己
    head.next = None                         # 自己变成尾巴
    return new_head
# 空间 O(n)（调用栈）—— 所以迭代版更优
```

## 面试怎么说

"三个指针 `prev`、`cur`、`nxt`。遍历链表，每步先把 `cur.next` 暂存到 `nxt`，再把 `cur.next` 指向 `prev` 完成掉头，然后两个指针各前进一步。循环结束时 `cur` 为空，`prev` 就是新头。时间 O(n)，**空间 O(1)**。关键是必须先暂存下一个节点，否则改完指针就丢了后半条链。递归版也能写，但空间是 O(n)。"
