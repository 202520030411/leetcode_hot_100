# 07 无重复字符的最长子串（Longest Substring Without Repeating Characters）

> 滑动窗口 · 中等 · **国内面试高频** · https://leetcode.cn/problems/longest-substring-without-repeating-characters/
> 🎞 **交互式可视化（能一步步点）**：https://claude.ai/artifact/HcKXvy47p6BAAizuK1549L

## 核心思路一句话

**`right` 一步步往右吞字符；一旦吞进来会重复，就从左边吐，吐到不重复为止；每次吞完更新最大长度。**

## 先分清两个词

- **子串 substring = 连续的一段**，必须挨着 → **滑动窗口**
- **子序列 subsequence = 可以跳着取**（顺序不变）→ 多半是动态规划

`"pwwkew"` 的答案是 `"wke"`(3) 不是 `"pwke"` —— 后者跳过了字符，是子序列。
（数组版的说法是**子数组 subarray**，同样是连续的一段。）

## 窗口是什么

**窗口 = 字符串上的一段连续区间，用 `left` 和 `right` 两个下标标出左右边界。**

```
s = "a  b  c  a  b  c  b  b"
     0  1  2  3  4  5  6  7
        [b  c  a]              窗口 = 下标 1~3
         ↑     ↑
        left  right

right += 1  →  右边张嘴吞一个字符（窗口变长）
left  += 1  →  左边吐掉一个字符（窗口变短）
```

两个下标都**只往右走、绝不回头** → 各自最多 n 步 → **O(n)**。

## ★ 我当初的卡点：「吐出去」是什么意思

**吐 = 两行代码，不是什么抽象概念：**

```python
window.remove(s[left])     # ① 把最左边那个字符从清单里删掉
left += 1                  # ② 左边界往右挪一格
```

**为什么这两行必须一起做？** 因为手上有两样东西，必须时刻同步：

```
left / right    →  标出窗口的范围（从第几格到第几格）
window (set)    →  记录窗口里现在有哪些字符  ← 一张清单
```

`left` 往右挪一格 → 最左那个字符被甩出窗口了 → **清单上必须把它划掉**，
否则下次问 `ch in window` 就问错了（清单上留着一个已经不在窗口里的字符）。

**一步一步看 `right=3` 那一轮：**

```
现在: 窗口 = 下标 0~2 "abc"，window = {'a','b','c'}，left=0

要吞 s[3]='a'
   'a' in window? → 是！不能吞，否则窗口里有两个 'a'
   吐一次: window.remove(s[0]) → window={'b','c'}
          left += 1           → left=1
   再问 'a' in window? → 不在了，可以吞
   window.add('a')            → window={'a','b','c'}
   窗口 = 下标 1~3 "bca" ✅
```

## 两个必须记住的细节

**① 必须用 `while` 不能用 `if`** —— 一次可能吐不干净。

`right=6` 那一轮连吐了两个：
```
窗口 "abc"(下标3,4,5)，要吞 s[6]='b'
   吐 'a' → window={'b','c'} → 'b' 还在！
   吐 'b' → window={'c'}     → 'b' 不在了，停
```

**② 窗口长度 = `right - left + 1`，那个 `+1` 不能漏。**

```
        [b  c  a]
         ↑     ↑
      left=1  right=3     长度 = 3-1+1 = 3  ✅（3-1=2 少算一个）
```

因为 `left` 和 `right` 指的格子**都算在窗口里**（左闭右闭）。
这是差一错误（off-by-one），和当初 `range(i, n)` 写成包含 `i` 是同一类。

## 完整代码

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()                           # 清单：窗口里有哪些字符
        left = 0
        best = 0
        for right in range(len(s)):              # for 管扩张
            ch = s[right]
            while ch in window:                  # while 管收缩，可能连吐好几个
                window.remove(s[left])           # 清单划掉最左那个
                left += 1                        # 左边界右移
            window.add(ch)                       # 吞进来
            best = max(best, right - left + 1)   # 窗口合法了，打擂台
        return best
```

`window.remove(x)` 是 set 的删除方法。空字符串天然返回 0，不用特判。

## 复杂度

时间 **O(n)**（`left`、`right` 各最多走 n 步，共 2n）。
空间 **O(min(n, 字符集大小))** —— 清单最多装下所有不同字符，ASCII 只有 128 个 → 实际 O(1)。

## ★★ 可复用的滑窗模板（真正的收获）

```python
left = 0
状态 = 初始值
for right in range(len(s)):
    # 1. 把 s[right] 纳入窗口，更新状态
    while 窗口不合法:
        # 2. 把 s[left] 移出窗口，更新状态
        left += 1
    # 3. 到这里窗口一定合法 → 更新答案
```

**`for` 管扩张，`while` 管收缩，收缩完更新答案。** 后面每道滑窗题都是往这三个空里填不同东西：

| | 本题 | 其他滑窗题 |
|---|---|---|
| 状态用什么存 | `set`（只需知道有没有） | `dict` 计数（需要知道有几个） |
| 「不合法」是什么 | 出现重复字符 | 各字符数量和目标不一致 / 和超过 k |
| 窗口长度 | 变长，求最大 | 有的是**固定长度**，不用收缩判断 |

> **注意本题是"先吐后吞"**（`while` 在 `window.add` 之前），因为 `set` 装不下两个相同字符。
> 用 `dict` 计数的题可以"先吞后吐"，那是模板的标准顺序。

## 面试怎么说

"用滑动窗口。`right` 负责扩张，一旦新字符和窗口内的重复，就从左边收缩直到不重复；
每次窗口合法时更新最大长度。两个指针都单向移动不回头，所以整体 O(n)，
空间是 O(min(n, 字符集大小))。"
