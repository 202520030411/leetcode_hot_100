### 二叉树（递归三步心法）

```
① 信任递归对更小的子树给出正确答案
② 想清楚拿到子树答案后怎么拼出自己的
③ 写出最小情况（空节点）—— 这是递归的刹车
```

**DP 四步流程**：① 定义 dp[i] ② 看最后一步 ③ 写转移方程（计数用 `+`、最优化用 `max`/`min`）④ 定 base case
**回溯模板**：做选择 → 递归 → **撤销选择**；记录答案必须 `path[:]` 拷贝

> **🔴 29 岛屿数量：2026-10-16 自评「太难」。** 重学时的建议入口：
> ① 先只看 1×2 的最小例子 `[["1","1"]]`，理解「不涂掉会重复计数」
> ② 再用「Photoshop 油漆桶点几下能涂完所有陆地」这个类比
> ③ 最后才看四个方向的递归写法
> 网格 DFS 是**链表/树递归之后的第三层抽象**（二维 + 回头路），先把树递归坐实再回来。

**队列 vs 栈决定搜索性格：**

```
队列（先进先出）→ BFS → 一层一层扩散 → 求「最少步数」
栈  （后进先出）→ DFS → 一条路走到底 → 求「有没有连通 / 所有路径」
```
