# 30 爬楼梯（Climbing Stairs）

> 动态规划 · 简单 · **DP 入门第一题** · https://leetcode.cn/problems/climbing-stairs/
> 🎞 https://claude.ai/artifact/WnP3uNP92wTMKAHgqhzfuJ

## 核心思路一句话

**`dp[i] = dp[i-1] + dp[i-2]`：到第 i 级的最后一步只能从 i-1 跨 1 级或从 i-2 跨 2 级。**

## 题目

| | |
|---|---|
| 给你 | 整数 `n`，楼梯有 n 级。每次只能爬 **1 级或 2 级** |
| 返回 | 爬到顶**一共有多少种不同走法** |

```
n=1 →  1 种      1
n=2 →  2 种      1+1 ｜ 2
n=3 →  3 种      1+1+1 ｜ 1+2 ｜ 2+1
n=4 →  5 种      1+1+1+1 ｜ 1+1+2 ｜ 1+2+1 ｜ 2+1+1 ｜ 2+2
n=45 → 1836311903    ← 不可能手列，所以需要算法
```

**⚠ 顺序不同算两种走法**（`1+2` 和 `2+1` 分别计数）。
**⚠ 不能跨 3 级**（规则只允许 1 或 2）。

## ★★ 推导：只看最后一步

**想爬到第 4 级，最后一步只有两种可能：**

```
① 从第 3 级跨 1 步上来  →  前面走到第 3 级有 f(3) = 3 种
② 从第 2 级跨 2 步上来  →  前面走到第 2 级有 f(2) = 2 种
没有第三种（一步最多 2 级）
         ↓
f(4) = f(3) + f(2) = 5  ✅
```

> **「看最后一步」是所有 DP 题的入口：**
> ① 问「到达目标的最后一步有哪几种可能」
> ② 每种可能对应一个更小的子问题
> ③ 把子问题的答案合并（计数题用 `+`，最优化题用 `max`/`min`）

这个公式的正式名字叫**状态转移方程** —— 名字不重要，它就是「这一格的值怎么由前面的格子算出来」。

## ★ DP 的本质：填一张表

```
i:      1    2    3    4    5    6
f(i):   1    2    3    5    8    13
             ↑    ↑    ↑
             └────┴────┘  每格 = 前两格之和
```

**为什么要「把答案记下来」？** 纯递归会疯狂重复计算：

| n | 纯递归调用次数 | DP 填表次数 |
|---|---|---|
| 20 | 13,529 | 20 |
| 40 | **204,668,309** | **40** |

（n=20 时 `f(13)` 被重复算了 21 次。）**DP 把每个答案存一次用多次，从指数级降到线性。**

## 代码

```python
# 版本 1：填表（直观）
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        dp = [0] * (n + 1)
        dp[1], dp[2] = 1, 2         # base case
        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
        return dp[n]
# 时间 O(n)，空间 O(n)
```

```python
# 版本 2：滚动变量（面试首选，空间 O(1)）
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        a, b = 1, 2                  # f(1), f(2)
        for _ in range(3, n + 1):
            a, b = b, a + b          # 整体往前滚一格
        return b
# 时间 O(n)，空间 O(1)
```

## ★ 两个关键细节

**① base case 必须单独填。** `dp[1]=1, dp[2]=2` 不能靠公式算（它们前面没有两格）。**所有 DP 都要先定好最开始的几格。**

**② 算 `dp[i]` 只需要前两格 → 不用存整张表。** `a, b = b, a + b` 靠 Python 的同时赋值（右边全算完才赋给左边）。
**「只保留需要的几格」是 DP 最常见的优化**，很多 DP 题都能从 O(n) 空间降到 O(1)。

## 面试怎么说

"设 `dp[i]` 为爬到第 i 级的方法数。到第 i 级的最后一步只能是从 i-1 跨 1 级或从 i-2 跨 2 级，所以 `dp[i] = dp[i-1] + dp[i-2]`，初始 `dp[1]=1, dp[2]=2`。时间 O(n)，空间可以用两个滚动变量降到 O(1)。本质是斐波那契，但关键是『看最后一步』这个推导。"
