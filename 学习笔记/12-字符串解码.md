## 这题在要求什么：解压缩

`k[内容]` 是压缩写法，意思是「内容重复 k 次」。把它展开就行。

```
3[a]          →  aaa
2[bc]         →  bcbc
3[a]2[bc]     →  aaa + bcbc  =  aaabcbc      两段各自展开再拼
2[abc]ef      →  abcabc + ef =  abcabcef     括号外的字符原样保留
```

## 嵌套：从里往外算（人的做法）

```
3[a2[c]]
    └──┘      最里面是 2[c] = cc
3[acc]
└────┘        只剩一层，展开 = accaccacc    ✅

2[2[2[a]]]  →  2[2[aa]]  →  2[aaaa]  →  aaaaaaaa（8 个 a）
```

**规则：最里面的括号必须最先算完** —— 外层的内容里包含内层的结果。

## ★ 为什么要用栈：程序只能从左到右读一遍

**你手算时眼睛可以来回扫，先找到最里面的括号。程序不行** —— 它从左到右一个字符一个字符读，读过不回头（否则反复扫就慢了）。

**从左往右的视角看 `2[2[a]b]`：**

```
读 '2'  →  记住要重复 2 次。手上 num=2
读 '['  →  进入一层。外层的 num=2 和已拼的 "" 必须留着（内层算完还要用）
           → 存档(2, "")，手上清空
读 '2'  →  手上 num=2
读 '['  →  又进一层。存档(2, "")，手上清空
读 'a'  →  手上 cur="a"
读 ']'  →  这层结束！手上的 "a" 就是这层内容
           读档取回 (2, "") → cur = "" + "a"*2 = "aa"
读 'b'  →  手上 cur="aab"     ← 外层的内容在继续拼
读 ']'  →  又一层结束。读档 (2, "") → cur = "" + "aab"*2 = "aabaab"  ✅
```

**三个关键点：**

**① 遇到 `[` 为什么一定要存档？** 手上只有一个 `cur`，要用它装内层内容，就必须先把外层装到一半的挪走。不存档，内层算完就忘了外层拼到哪。

**② 遇到 `]` 为什么就能合并？** `]` 正好宣告「这一层结束」，此时手上的 `cur` **恰好就是这一层的完整内容**。

**③ 栈的「后进先出」自动实现了「从里往外」：**

```
手算：  最里面的括号最先算完
栈：    最后存的档最先被读  =  最内层最先合并完
                ↑ 同一回事
```

**所以根本不需要「找最里面的括号」这个动作** —— 老实从左到右读一遍，栈的性质会保证合并顺序是从里到外的。

## 四种字符，四件事

| 看到 | 做什么 |
|---|---|
| **数字** | 攒进 `num`（可能多位） |
| **`[`** | **存档**：`num` 和 `cur` 分别压栈，然后手上清空 |
| **`]`** | **读档**：弹出 `k` 和 `prev`，算 `cur = prev + cur * k` |
| **字母** | `cur += ch` |

手上只有两个工作变量：`cur`（这层正在拼的）、`num`（攒着还没用的次数）。
两个栈是存档区：`num_stack`（各层次数）、`str_stack`（各层进括号前已拼好的部分）。

## 多位数字怎么攒

`"100[a]"` 里 `100` 是三个独立字符：

```python
num = num * 10 + int(ch)

'1' →  0*10 + 1 = 1
'0' →  1*10 + 0 = 10
'0' → 10*10 + 0 = 100
```

**每来一位，已有的数往左挪一位（乘 10），新数字加到末位。**

## Python 零件

```python
ch.isdigit()      # 这个字符是数字吗？'3'→True, 'a'→False
int(ch)           # '3' 变成数字 3
"ab" * 3          # "ababab"  ← 字符串乘整数 = 重复，和 [0]*26 同一个规则
cur += ch         # 字符串拼接
```

## 完整代码

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stack, str_stack = [], []      # 存档区
        cur, num = "", 0                   # 手上的两个工作变量
        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)   # 攒次数（可能多位）
            elif ch == '[':
                num_stack.append(num)      # 存档：外层的次数
                str_stack.append(cur)      # 存档：外层拼到一半的字符串
                num, cur = 0, ""           # 手上清空，专心算内层
            elif ch == ']':
                k = num_stack.pop()        # 读档
                prev = str_stack.pop()
                cur = prev + cur * k       # 外层的 + 这层重复 k 次
            else:
                cur += ch
        return cur
```

## 两个容易错的地方

**① `num, cur = 0, ""` 必须在两个 `append` 之后。** 顺序反了就存进去两个空值。

**② 合并顺序是 `prev + cur * k`，不能反。** `prev` 是先拼出来的（外层），必须在前面。
写成 `cur * k + prev` 的话 `"2[abc]3[cd]ef"` 会乱序。

## 复杂度

时间 **O(解码后的长度)** —— 每个输出字符被拼接的次数有限。空间 **O(嵌套层数 + 输出长度)**。

## 面试怎么说

"用两个栈。遇到数字就按 `num*10+d` 攒多位数；遇到 `[` 把当前的次数和已拼好的字符串压栈、手上清空；
遇到 `]` 弹出次数 `k` 和外层字符串 `prev`，令 `cur = prev + cur*k`；普通字母直接追加。
栈的后进先出天然保证最内层先结算，所以一次遍历就能完成从内到外的展开。"
