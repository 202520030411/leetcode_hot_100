# 10 有效的括号（Valid Parentheses）

> 栈 · 简单 · **栈的最佳入门题** · https://leetcode.cn/problems/valid-parentheses/
> 🎞 **交互式可视化**（栈画成一摞盘子）：https://claude.ai/artifact/Jo53EYUUQMGkjYYZD7kiZU

## 栈是什么

**一摞盘子：只能从同一头进出。** 放盘子放最上面，拿盘子也只能从最上面拿。

```
放入顺序：a → b → c          拿出顺序：c → b → a
     ┌───┐
     │ c │ ← 栈顶（最上面）     最后放进去的，最先被拿出来
     ├───┤
     │ b │
     ├───┤
     │ a │ ← 最底下
     └───┘
```

（这个规则正式名字叫**后进先出** / LIFO，名字不重要。）

**Python 里不用学新结构，直接用 list：**

```python
stack = []
stack.append(x)     # 放到最上面
stack.pop()         # 拿走最上面那个，并返回它
stack[-1]           # 只看一眼栈顶，不拿走
not stack           # 栈空吗？（空 list 在 if 里算 False）
len(stack)          # 现在有几个
```

**`not stack` 要记住**：Python 里空的 list/dict/set/字符串在 `if` 里都算 `False`。所以 `if not stack:` 读作「如果栈空了」。

## 核心思路一句话

**左括号入栈；右括号来了只能和栈顶配对（栈顶就是「最近一个还没闭合的左括号」）；走完后栈必须空。**

## 为什么非要用栈

**因为括号是嵌套的 —— 最新打开的必须最先关闭。**

```
{  [  (  )  ]  }
↑  ↑  ↑  ↑  ↑  ↑
1  2  3  3  2  1     ← 3 号最后开，所以 3 号最先关
```

「最近未闭合的那个」= 「最后放进去的那个」= **栈顶**。这正好是栈的规则。

```
"([)]"                          "{[]}"
( 记下                           { 记下
[ 记下 → 栈顶是 [                 [ 记下 → 栈顶是 [
) 来了，栈顶是 [ ≠ ( → ❌          ] 来了，栈顶是 [ ✅ 拿走
                                 } 来了，栈顶是 { ✅ 拿走
                                 栈空 → true
```

## ★ 三种失败情况，一个都不能漏

```
① 类型不对      "(]"     右括号来了，栈顶的左括号类型不匹配
② 右括号太多    "())"    右括号来了，但栈是空的（没有左括号可配）
③ 左括号太多    "(("     字符串走完了，栈里还剩东西
```

**② 和 ③ 最容易漏。**
- ② 对应 `if not stack: return False`
- ③ 对应最后那行 `return not stack`（**不是 `return True`**）

## pairs 的方向

```python
pairs = {')': '(', ']': '[', '}': '{'}      # 右括号 → 它该配的左括号
```

**为什么右括号当键？** 口诀：**拿着什么去查，什么当键。** 遇到右括号时才需要查「它该配哪个左括号」，手上拿着右括号 → 右括号当键。

**一箭双雕**：`if ch in pairs` 直接就是「ch 是不是右括号」的判断 —— 这本表的键恰好是全部三个右括号，不用再写 `if ch in ')]}'`。

## ★ 两个检查的顺序不能换

```python
if not stack or stack[-1] != pairs[ch]:
   ↑              ↑
 栈空就 True    栈空时这边根本不会被执行
 直接短路
```

**如果先写 `stack[-1] != pairs[ch]`，栈空时 `stack[-1]` 直接报 `IndexError: list index out of range`。**

靠的是 `or` 的**短路**：左边成立就根本不算右边。
同一个机制在第 06 题用过：`i > 0 and nums[i] == nums[i-1]`，`i=0` 时压根不碰 `nums[-1]`。

## 我踩过的坑

| 我写的 | 正确 | 报错 |
|---|---|---|
| `stack.append[ch]` | `stack.append(ch)` | `TypeError: 'builtin_function_or_method' object is not subscriptable` |

**`()` 和 `[]` 的区别：**

```
()  =  做一个动作（调用）
[]  =  从容器里取东西
```

```
动作 → 圆括号：  append(x)  pop()  len(x)  max(a,b)  sorted(x)  set(x)
容器 → 方括号：  stack[0]   pairs[ch]  nums[i]  seen[num]  count[prefix]
```

我在同一行里 `pairs[ch]` 对了（容器取值）、`append[ch]` 错了（动作要圆括号）。
**判断：这个名字是「动作」还是「容器」？**

| 报错 | 意思 | 怎么改 |
|---|---|---|
| `object is not subscriptable` | 方括号用在了函数/方法上 | 改成 `()` |
| `object is not callable` | 圆括号用在了容器上 | 改成 `[]` |

## 完整代码

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pairs = {')': '(', ']': '[', '}': '{'}   # 右括号 -> 它该配的左括号
        stack = []
        for ch in s:
            if ch in pairs:                       # 是右括号
                if not stack or stack[-1] != pairs[ch]:
                    return False                  # 栈空了 或 类型不对
                stack.pop()                       # 匹配成功，栈顶拿走
            else:                                 # 是左括号
                stack.append(ch)
        return not stack                          # 栈空才算全部闭合
```

## 复杂度

时间 **O(n)**（每个字符进出栈各最多一次），空间 **O(n)**（最坏全是左括号）。

## 面试怎么说

"用栈。左括号入栈；右括号来时和栈顶比对，栈空或类型不匹配就返回 False，匹配就弹出栈顶。
遍历结束后栈必须为空，否则有左括号没闭合。时间空间都是 O(n)。
关键是栈顶永远是『最近一个还没闭合的左括号』，正好对应括号嵌套的规则。"
