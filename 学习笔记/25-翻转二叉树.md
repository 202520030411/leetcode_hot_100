# 25 翻转二叉树（Invert Binary Tree）

> 二叉树 · 简单 · https://leetcode.cn/problems/invert-binary-tree/

## 核心思路一句话

**递归交换每个节点的左右孩子。**

## 题目

| | |
|---|---|
| 给你 | 二叉树根节点 `root` |
| 返回 | 左右镜像翻转后的树（**要返回 root**） |

```
     4                    4
   /   \                /   \
  2     7      →       7     2
 / \   / \            / \   / \
1   3 6   9          9   6 3   1
```

## 代码

```python
class Solution:
    def invertTree(self, root: TreeNode) -> TreeNode:
        if not root:
            return None
        root.left, root.right = root.right, root.left    # 交换自己的两个孩子
        self.invertTree(root.left)                        # 递归处理（交换后的）两边
        self.invertTree(root.right)
        return root
```

**更紧凑的写法：**

```python
def invertTree(self, root):
    if not root: return None
    root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
    return root
```

## ★ 三个细节

**① `a, b = b, a` 交换不需要临时变量** —— Python 的同时赋值（右边先全算完再赋给左边）。你在移动零那题见过。

**② 必须 `return root`** —— 题目要的是整棵树，不是 None。漏了会返回 None。

**③ 前序后序都行** —— 先交换自己再递归、或先递归再交换自己，结果一样（因为交换是对称操作，不依赖孩子的结果）。
**对比最近公共祖先：那题必须后序，因为要用到孩子的返回值。**

## 复杂度

时间 **O(n)**，空间 **O(h)**。

## 面试怎么说

"递归。每个节点交换它的左右孩子，然后对交换后的两个子树递归做同样的事。终止条件是空节点返回 None，最后要返回 root。时间 O(n)，空间 O(h)。这题前序后序都可以，因为交换操作不依赖子树的返回结果。"
