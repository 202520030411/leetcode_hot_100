# 22 相交链表（Intersection of Two Linked Lists）

> 链表 · 简单 · **换道跑技巧** · https://leetcode.cn/problems/intersection-of-two-linked-lists/
> 🎞 https://claude.ai/artifact/JXDR4aKnYBwGGFpyxcpMPU

## 核心思路一句话

**两个指针各走一条链，走到尽头就跳到对方的头继续 —— 两条路长度都变成 `a+c+b`，必然同时到达交点。**

## 题目

| | |
|---|---|
| 给你 | 两条链表的头 `headA`、`headB` |
| 返回 | 它们**开始相交的那个节点**；不相交返回 `None` |

```
A:  4 → 1 ↘
            8 → 4 → 5 → None     ← 从节点 8 开始共用后面所有节点
B:  5 → 6 → 1 ↗

返回：值为 8 的那个节点

A:  2 → 6 → 4 → None
B:  1 → 5 → None                 ← 完全分开
返回：None
```

> **⚠ 「相交」指的是【同一个节点对象】，不是值相同。** 上面 A 有个 1、B 也有个 1，但它们是不同的盒子，不算相交。（和第 20 题同一个概念。）

## 解法一：朴素

```python
seen = set()
cur = headA
while cur:                # 把 A 的所有节点扔进 set
    seen.add(cur); cur = cur.next
cur = headB
while cur:                # 遍历 B，第一个在 set 里的就是交点
    if cur in seen: return cur
    cur = cur.next
return None
# 时间 O(m+n)，空间 O(m)
```

## ★★ 解法二：换道跑（空间 O(1)）

**问题**：两条链长度不同，不能简单地「同时往前走」—— 它们不会同时到交点。

```
A:  4 → 1 → 8 → 4 → 5          A 独有 a=2 个 + 公共 c=3 个
B:  5 → 6 → 1 → 8 → 4 → 5      B 独有 b=3 个 + 公共 c=3 个
```

**技巧：走到自己的尽头就换到对方的头继续走。**

```
指针 p：走完 A（a+c）→ 换到 B 头，走 B 独有的（b）  →  总共 a + c + b
指针 q：走完 B（b+c）→ 换到 A 头，走 A 独有的（a）  →  总共 b + c + a
                                                      ↑ 完全相同！
```

**既然总步数相同，它们必然在同一时刻到达交点**（不相交时则同时变成 `None`）。

> **换句话说：这个技巧把「两条不等长的路」拼成了「两条等长的路」。**

## 代码

```python
class Solution:
    def getIntersectionNode(self, headA, headB):
        p, q = headA, headB
        while p != q:                        # ★ 比节点，不是比值
            p = p.next if p else headB       # 到头就换到 B
            q = q.next if q else headA       # 到头就换到 A
        return p                             # 交点，或 None
```

## ★ 三个关键细节

**① `while p != q` 比的是节点身份。** 值全一样也不会误判。

**② 不相交时不需要特判。** 两者会同时变成 `None`，而 `None == None` 成立，循环自然退出并返回 `None`。

**③ 每个指针只换道一次。** `p = p.next if p else headB` —— 到头了（p 是 None）就跳到**对方**的头。

## 复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| set 记录 | O(m+n) | O(m) |
| 换道跑 | O(m+n) | **O(1)** ← 优势在这 |

> **⚠ 面试被问「为什么用双指针」，答「时间一样，空间从 O(m) 降到 O(1)」。别答「更快」，会被纠正。**

## 面试怎么说

"两条链长度不同，所以不能同步走。技巧是让两个指针各走一条链，走到尽头就换到对方的头继续 —— 这样两个指针走的总长度都是 `a+c+b`，必然同时抵达交点；不相交时会同时变成 None，循环自然结束返回 None，不需要特判。注意比较的是节点身份不是值。时间 O(m+n)，空间 O(1)。"
