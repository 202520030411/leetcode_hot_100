# 28 二叉树的层序遍历（Binary Tree Level Order Traversal）

> BFS · 中等 · **队列入门** · https://leetcode.cn/problems/binary-tree-level-order-traversal/
> 🎞 https://claude.ai/artifact/5PD7rzBTAow5vywGTJXAC7

## 核心思路一句话

**队列 BFS；每轮进循环先用 `size = len(q)` 固定住当前层的个数，只处理这么多个。**

## 题目

| | |
|---|---|
| 给你 | 二叉树根节点 `root` |
| 返回 | **按层分组**的节点值：每个子列表装一层，从上到下、每层从左到右 |

```
        3            第 0 层: [3]
       / \           第 1 层: [9, 20]
      9   20         第 2 层: [15, 7]
         /  \
        15   7

输出: [[3], [9,20], [15,7]]      ← 不是平铺的 [3,9,20,15,7]

root = []    →  []       （空列表，不是 [[]]）
root = [1]   →  [[1]]
```

## BFS vs DFS：走法完全不同

```
DFS（递归）：一条路走到底，再回头        1 → 2 → 4 →（回头）→ 5 → 3
BFS（队列）：一圈一圈往外扩              第0层 → 第1层 → 第2层
```

**类比：DFS 是走迷宫（一条路走死再退回）；BFS 是水波纹扩散（先淹一圈，再淹下一圈）。**

### ★ BFS 的杀手级应用：最少步数

> **BFS 严格按层扩散，所以「第一次碰到目标时走的层数，必然是最少步数」。**

```
求「最少几步 / 最短路径 / 最少几分钟」  →  BFS
求「所有路径 / 树的深度 / 有没有连通」  →  DFS 递归更简洁
```

## 工具：队列（和栈正好相反）

```
栈   stack：后进先出  —— 一摞盘子
队列 queue：先进先出  —— 排队买票
```

```python
from collections import deque

q = deque([root])
q.append(x)              # 进队（队尾）
node = q.popleft()       # 出队（队头）★ 不是 pop
len(q)                   # 几个
while q:                 # 非空就继续
```

> **⚠ 必须用 `deque.popleft()`，不能用 `list.pop(0)`** —— 前者 O(1)，后者要搬移整个列表是 O(n)。**面试里用 list 做队列会被指出来。**

## ★★ 关键技巧：`size = len(q)`

**问题**：队列里会同时混着「这一层剩下的」和「下一层刚进来的」，怎么知道一层到哪结束？

```
队列: [3]              size = 1  → 处理 1 个 → 这一层 [3]
      处理 3 时把 9, 20 放进队列
队列: [9, 20]          size = 2  → 处理 2 个 → 这一层 [9, 20]
      处理过程中把 15, 7 放进队列
队列: [15, 7]          size = 2  → 这一层 [15, 7]
                        ↑ 进循环时就固定住了，后面新进来的不算这一层
```

**如果只要平铺的结果，根本不需要 `size`：**

```python
while q:
    node = q.popleft()
    res.append(node.val)          # 平铺，不分层
    if node.left:  q.append(node.left)
    if node.right: q.append(node.right)
```

**`size` 存在的唯一理由就是「要分层」。**

## 代码

```python
from collections import deque

class Solution:
    def levelOrder(self, root: TreeNode) -> List[List[int]]:
        if not root:
            return []
        res = []
        q = deque([root])
        while q:
            size = len(q)                      # ★ 固定住这一层的个数
            level = []
            for _ in range(size):              # 只处理这一层
                node = q.popleft()
                level.append(node.val)
                if node.left:  q.append(node.left)    # 孩子进队，留给下一层
                if node.right: q.append(node.right)
            res.append(level)
        return res
```

**`for _ in range(size)` 里的 `_`** 是「我不关心这个变量」的惯用名字 —— 只需要循环 size 次。

## 建立在层序之上的其他题

| 题 | 靠层序的什么 |
|---|---|
| 二叉树的右视图 | 每层**最后一个** |
| 二叉树的最大宽度 | 哪一层**最宽** |
| 每层最大值 | 每层取 max |
| 二叉树的最小深度 | **第一次**碰到叶子是第几层 |

## 复杂度

时间 **O(n)**，空间 **O(n)**（队列最宽的那一层）。
满二叉树时队列每层翻倍（最宽 n/2）；退化成链表时队列始终只有 1 个。

## 面试怎么说

"用队列做 BFS。关键是每轮进循环时先用 `size = len(q)` 固定住当前层的节点数，然后只弹出这么多个归为一层，处理时把它们的孩子放进队尾留给下一层。时间 O(n)，空间 O(n)，取决于最宽的那一层。注意要用 `deque.popleft()` 而不是 `list.pop(0)`，后者是 O(n)。"
