# 31 打家劫舍（House Robber）

> 动态规划 · 中等 · **最优化 DP 入门** · https://leetcode.cn/problems/house-robber/
> 🎞 https://claude.ai/artifact/6HvW4QSU42SQ4Eisi3pJ3x

## 核心思路一句话

**对每一家只有「偷」或「不偷」两个选择：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。**

## 题目

| | |
|---|---|
| 给你 | 一排房子，`nums[i]` 是第 i 家的钱 |
| 规则 | **不能偷相邻两家**（会触发警报） |
| 返回 | 最多能偷到多少钱 |

```
nums = [2, 7, 9, 3, 1]

所有合法偷法（部分）：
   只偷 1 家:  2 ｜ 7 ｜ 9 ｜ 3 ｜ 1
   偷 2 家:    0+2 → 11    0+3 → 5    1+3 → 10    1+4 → 8    2+4 → 10
   偷 3 家:    0+2+4 → 2+9+1 = 12   ★ 最大
不合法: 0+1 ❌  1+2 ❌  2+3 ❌（相邻）

输出: 12
```

```
nums = [1, 2, 3, 1]
   0+2 → 1+3 = 4 ★    1+3 → 2+1 = 3    0+3 → 1+1 = 2
输出: 4
```

## ★ 贪心不行

```
nums = [2, 7, 9, 3, 1]
贪心「先偷最大的 9」→ 7 和 3 都不能偷了 → 只能再偷 1 → 共 10
最优 2 + 9 + 1 = 12  ✅

nums = [2, 1, 1, 2]
最优是偷两端 2+2 = 4，贪心从任何最大值开始都拿不到
```

## 思路：看最后一个决策

**`dp[i]` 的定义：前 i+1 家（下标 0..i）里能偷到的最大金额。**

```
① 偷第 i 家   →  第 i-1 家不能偷  →  只能从 dp[i-2] 接上
                 金额 = dp[i-2] + nums[i]
② 不偷第 i 家 →  前 i-1 家怎么偷都行，直接继承
                 金额 = dp[i-1]

dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

**「偷」这个选项跳过 i-1，从 dp[i-2] 接上 —— 这就是「不能相邻」在公式里的体现，也是为什么要往前看两格。**

## ★★ 和爬楼梯对比：DP 的两大类

```
爬楼梯:     dp[i] = dp[i-1] + dp[i-2]                  ← 加法，求【总数】
打家劫舍:   dp[i] = max(dp[i-1], dp[i-2] + nums[i])     ← 取 max，求【最优】
                    ↑ 骨架一样（都只看前两格），差别在「怎么合并」
```

| | 计数型 DP | 最优化 DP |
|---|---|---|
| 问的是 | 有多少种方法 | 最大/最小值 |
| 合并方式 | **相加** | **取 max / min** |
| 例子 | 爬楼梯、不同路径 | 打家劫舍、最大子数组和、零钱兑换 |

> **听完题目先判断是「数数」还是「求最优」，就知道转移方程里该用 `+` 还是 `max`。**

## 代码

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2, prev1 = 0, 0          # dp[i-2], dp[i-1]
        for x in nums:
            prev2, prev1 = prev1, max(prev1, prev2 + x)
        return prev1
# 时间 O(n)，空间 O(1)，连 base case 都不用特判
```

**填表版（更直观）：**

```python
n = len(nums)
if n == 1: return nums[0]
dp = [0] * n
dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])        # 前两家相邻，只能偷大的
for i in range(2, n):
    dp[i] = max(dp[i-1], dp[i-2] + nums[i])
return dp[n-1]
```

## ★ 容易误解的一点

**`dp[i]` 不代表「第 i 家被偷了」**，它代表「前 i+1 家里最多能偷多少」。所以 dp 值只会递增或持平，不会下降。
**最优方案具体偷了哪几家，要走到最后回溯才知道。**

## 面试怎么说

"设 `dp[i]` 为前 i+1 家能偷到的最大金额。对第 i 家只有两个选择：偷它就不能偷 i-1，所以是 `dp[i-2] + nums[i]`；不偷它就直接继承 `dp[i-1]`。取两者最大。时间 O(n)，用两个滚动变量空间 O(1)。贪心不行 —— `[2,7,9,3,1]` 先偷最大的 9 只能得 10，而最优是 2+9+1=12。"
