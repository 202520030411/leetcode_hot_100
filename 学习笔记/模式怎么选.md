# 模式怎么选（哈希 / 双指针 / 滑动窗口 的区别）

> 复习时最常糊的地方。**区别只有两件事：几个指针、有没有账本。**

## 核心对照表

| | 几个指针 | 有账本吗 | 账本记什么 | 回答什么问题 |
|---|---|---|---|---|
| **哈希表** | **1 个**（普通遍历） | 有 | **历史上所有见过的** | "这个东西之前出现过吗" |
| **双指针** | **2 个** | **没有** | — | "这两个位置上的值怎么样" |
| **滑动窗口** | **2 个**（都朝右） | 有 | **只记两指针之间那一段** | "当前这一段满足条件吗" |

**滑动窗口 = 双指针 + 一本账。** 它不是独立的第三种东西。

## 同一件事，三种走法

```
哈希表（两数之和，target=9）—— 一个指针往右，账本只增不减
  [2]  7   11  15        账本 {2}
   2  [7]  11  15        账本 {2,7}    ← 问「9-7=2 在账本里吗」→ 在！返回
                                          ↑ 账本里永远留着 2，哪怕早就走过

双指针·相向（盛水容器）—— 两个指针从两端往中间，完全没有账本
  [1]  8   6   2   5  [7]     只比较 height[left] 和 height[right]
   1  [8]  6   2   5  [7]     矮的那端往里挪
   1  [8]  6   2  [5]  7      永远只看当前两格，不记历史

滑动窗口（无重复字符）—— 两个指针都朝右，账本只记中间那段
  [a]  b   c   a         账本 {a}
  [a   b]  c   a         账本 {a,b}
  [a   b   c]  a         账本 {a,b,c}
   a  [b   c   a]        账本 {b,c,a}   ← a 出了窗口，账本上划掉它！
```

## ★ 最本质的一条

```
哈希表的账本：    只进不出  ──▶  记「历史上所有见过的」
滑动窗口的账本：  有进有出  ──▶  记「当前这一段里的」
```

- 第 01 题 `seen[num] = i` **永远不删** —— 哪怕那个数在很前面，也还要能查到
- 第 07 题 `window.remove(s[left])` **必须删** —— 那个字符已不在窗口里，留着账本就对不上

**我当初卡在「吐出去是啥意思」，根源就是这个区别。哈希不用吐，滑窗必须吐。**

## 判断只要问三个问题

```
Q1: 答案是「一段连续的区间」吗？（子串/子数组/"连续"）
     是 ──▶ 滑动窗口

Q2: 不是连续区间。数组「有序」吗？要「原地修改」吗？
     是 ──▶ 双指针
     （有序 → 相向夹；原地改 → 同向一读一写）

Q3: 都不是，而我要反复问「这个值之前出现过吗 / 出现几次」？
     ──▶ 哈希表
```

**验算：**

| 题 | Q1 连续区间? | Q2 有序/原地? | 结论 |
|---|---|---|---|
| 01 两数之和 | 否（两数不用相邻） | 否 | **哈希** |
| 04 移动零 | 否 | **原地改** | **双指针同向** |
| 05 盛水容器 | 否（两柱不用相邻） | 两端求最优 | **双指针相向** |
| 07 无重复最长子串 | **是**（子串） | — | **滑窗变长** |
| 08 字母异位词 | **是**（子串，长度固定） | — | **滑窗固定** |

## 关键词 → 模式 速查

```
"有序" / "排好序"          →  相向双指针、二分查找
"原地" / "不用额外空间"      →  双指针同向
"是否存在" / "重复"         →  哈希 set
"出现次数" / "分组"         →  哈希 dict
"子串"/"子数组" + 最长/最短  →  滑动窗口
"连续"                    →  滑动窗口（但数组有负数要警惕，见 09 题）
"所有的xxx组合"            →  回溯（还没学）
```

## ★ 一组经典对照：同一个问题，有序和无序解法不同

| | 两数之和（无序，第 01 题） | 两数之和 II（**有序**，LeetCode 167） |
|---|---|---|
| 解法 | 哈希表 | **相向双指针** |
| 时间 | O(n) | O(n) |
| 空间 | O(n) | **O(1)** ← 这就是「有序」换来的 |

**用哈希做有序版不算错，但面试官一定追问「数组有序这个条件你用上了吗」。**
题目给的每个条件都是线索，给了不用就是丢分。

## ★ 求「和」用相向，求「差」用同向

**相向双指针对「差」是失效的。** `[1,2,3,4,5]` 找差 = 2：

```
相向：left=0(值1) right=4(值5)  差=4 太大，要减小
      left++  →  (2,5) 差=3   变小了
      right-- →  (1,4) 差=3   也变小了
                 ↑ 两个方向都只能让差变小，没办法增大 ❌ 方向盘坏了
```

对比求「和」：`left++` 和变大、`right--` 和变小 —— **两个方向都有** ✅

**「差」要用同向双指针（两个都朝右）：**

```python
i = j = 0
while j < len(nums):
    d = nums[j] - nums[i]
    if d == k:   记录; i += 1; j += 1
    elif d < k:  j += 1        # 差太小 → 右边往右，差变大 ↑
    else:        i += 1        # 差太大 → 左边往右，差变小 ↓
```

```
两端往中间夹（相向）  →  适合「和」
两个都朝右（同向）    →  适合「差」，也是所有滑动窗口的形态
```

> **「两个指针都朝右」就是滑动窗口的形态。同向双指针和滑动窗口本来就是同一家。**
> 区别只在有没有维护「窗口内容的账本」：维护了就叫滑窗，只比较两格的值就叫双指针。

## 容易混的一对：双指针同向 vs 哈希

| | 双指针·同向 | 哈希表 |
|---|---|---|
| 干什么 | **原地改数组**（搬运、覆盖） | 只是**查**，不动原数组 |
| 特征 | 一个指针读、一个指针写 | 边走边往 `set`/`dict` 里存 |
| 例子 | 移动零、原地去重 | 判断有没有重复 |

**要不要改数组，就是分界线。** 双指针同向是"搬东西"的工具；只问"有没有"时没东西要搬 → 哈希。
