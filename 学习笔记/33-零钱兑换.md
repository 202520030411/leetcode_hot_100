# 33 零钱兑换（Coin Change）

> 动态规划 · 中等 · **多选择 DP** · https://leetcode.cn/problems/coin-change/
> 🎞 https://claude.ai/artifact/Jtt1GhSxVvFes94XZJmGoS

## 核心思路一句话

**`dp[i] = min(dp[i-coin] + 1)` 枚举所有面额：最后一枚用哪种硬币，取枚数最少的。**

## 题目

| | |
|---|---|
| 给你 | 面额数组 `coins`（每种**无限多枚**）、目标金额 `amount` |
| 返回 | 凑出 `amount` 的**最少硬币枚数**；**凑不出返回 -1** |

```
coins = [1, 2, 5],  amount = 11
   5 + 5 + 1        = 11  →  3 枚   ★ 最少
   5 + 2 + 2 + 2    = 11  →  4 枚
   1×11             = 11  →  11 枚
输出: 3

coins = [2],  amount = 3     凑不出（2 差 1，2+2 超了）
输出: -1

coins = [1],  amount = 0     不需要硬币
输出: 0                      ← 边界：金额 0 返回 0
```

## ★ 贪心为什么不行

```
coins = [1, 3, 4],  amount = 6
贪心：先拿 4 → 剩 2 → 拿 1 → 拿 1     共 3 枚
最优：3 + 3                        共 2 枚  ✅
```

**贪心被「4」带进死胡同。** 必须把所有可能都试一遍 → DP。

## 思路：最后一步用的是哪一枚硬币

**`dp[i]` 的定义：凑出金额 `i` 所需的最少硬币数。**

```
最后一枚用 1 元  →  前面要凑 i-1  →  dp[i-1] + 1 枚
最后一枚用 2 元  →  前面要凑 i-2  →  dp[i-2] + 1 枚
最后一枚用 5 元  →  前面要凑 i-5  →  dp[i-5] + 1 枚

dp[i] = min(这几个候选)
```

## ★★ 和前三题的区别：候选不是 2 个

```
爬楼梯:      最后一步 2 种（跨 1 级 / 跨 2 级）        → 看前 2 格
打家劫舍:    最后一步 2 种（偷 / 不偷）                → 看前 2 格
零钱兑换:    最后一步 len(coins) 种（用哪个面额）      → ★ 内层循环遍历所有面额
```

## 代码

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [float("inf")] * (amount + 1)      # inf 表示「暂时凑不出」
        dp[0] = 0                                # base case：凑 0 元需要 0 枚
        for i in range(1, amount + 1):
            for coin in coins:                   # 试每一种面额
                if coin <= i:                    # 硬币不能比当前金额大
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        return dp[amount] if dp[amount] != float("inf") else -1
# 时间 O(amount × len(coins))，空间 O(amount)
```

## ★ 四个关键细节

**① `float("inf")` 是 Python 的正无穷**，表示「这个金额目前凑不出」。它在 `min` 里永远输，所以不用特判。

**② `dp[0] = 0` 是整张表的起点** —— 所有答案都是从它一枚一枚加上来的。

**③ `if coin <= i` 必须有。** 否则 `dp[i - coin]` 会用到**负下标** —— Python 负下标不报错，会静默取到末尾的值给出错误答案。**又是「先查边界再查内容」。**

**④ 最后要判断 `dp[amount]` 是否还是 `inf`** —— 是的话返回 -1。

## 复杂度

时间 **O(amount × 面额数)**，空间 **O(amount)**。

## 面试怎么说

"设 `dp[i]` 为凑出金额 i 的最少硬币数，初始化为无穷大，`dp[0] = 0`。对每个金额 i，枚举每种面额 coin：如果最后一枚用 coin，那前面需要凑出 `i - coin`，候选是 `dp[i-coin] + 1`，取所有候选的最小值。最后如果 `dp[amount]` 还是无穷大就返回 -1。时间 O(amount × 面额数)，空间 O(amount)。贪心不行，`coins=[1,3,4], amount=6` 时贪心拿 4 得 3 枚，最优是 3+3 两枚。"
