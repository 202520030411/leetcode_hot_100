# 24 二叉树的三种遍历（前序 / 中序 / 后序）

> 二叉树 · **所有树题的基本功** · 中序遍历：https://leetcode.cn/problems/binary-tree-inorder-traversal/
> 🎞 https://claude.ai/artifact/HYf7eHmu4BD89V7cQLtxuF

## 核心思路一句话

**「序」指的是【根】在什么位置。左右的相对顺序永远是「左在前」，变的只有根。**

## 三种遍历

```
        1
       / \
      2   3
     / \
    4   5
```

| 遍历 | 顺序 | 这棵树的结果 |
|---|---|---|
| **前序** preorder | **根** → 左 → 右 | `1 2 4 5 3` |
| **中序** inorder | 左 → **根** → 右 | `4 2 5 1 3` |
| **后序** postorder | 左 → 右 → **根** | `4 5 2 3 1` |

## 代码：三者只差 `visit` 那一行的位置

```python
def preorder(root):            def inorder(root):           def postorder(root):
    if not root: return            if not root: return          if not root: return
    visit(root)        # 根        inorder(root.left)           postorder(root.left)
    preorder(root.left)            visit(root)      # 根        postorder(root.right)
    preorder(root.right)           inorder(root.right)          visit(root)     # 根
```

**中序遍历（LeetCode 94）的完整写法：**

```python
class Solution:
    def inorderTraversal(self, root: TreeNode) -> List[int]:
        res = []
        def dfs(node):
            if not node:
                return
            dfs(node.left)
            res.append(node.val)      # 根在中间
            dfs(node.right)
        dfs(root)
        return res
```

## ★★ 两个必须记住的结论（高频考点）

**① 中序遍历二叉搜索树（BST）会得到升序序列。**

> BST 的定义是「左子树全部小于根，右子树全部大于根」，而中序正好按「左→根→右」访问 —— 出来就是从小到大。

```
      2                  中序: 1 2 3     ✅ 升序
     / \
    1   3

      4                  中序: 1 2 3 4 5 6 7
    /   \
   2     6
  / \   / \
 1   3 5   7
```

**「验证二叉搜索树」「BST 中第 K 小的元素」这两道题直接用这一条。**

**② 后序适合「需要先知道孩子结果」的题。**

> 比如最大深度：必须先拿到左右子树的深度才能算自己 —— 那就是后序的结构。
> **凡是「自底向上汇总」的题都是后序。** 最近公共祖先也是。

## 迭代写法（面试可能追问）

**中序的迭代版用栈模拟：**

```python
def inorderTraversal(self, root):
    res, stack, cur = [], [], root
    while cur or stack:
        while cur:                 # 一路往左走到底，边走边压栈
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()          # 弹出最左的
        res.append(cur.val)        # 访问它
        cur = cur.right            # 转向右子树
    return res
```

**面试里先给递归版（三行，清楚），被追问「不用递归怎么写」再给这个。**

## 复杂度

时间 **O(n)**，空间 **O(h)**（递归栈 / 显式栈），最坏 O(n)。

## 面试怎么说

"三种遍历的区别只在访问根节点的时机：前序是根左右、中序是左根右、后序是左右根，代码上只差 `visit` 那一行的位置。关键结论是中序遍历 BST 会得到升序序列，所以验证 BST、找 BST 第 K 小都用中序；而需要先汇总孩子结果的题（比如求深度、最近公共祖先）用后序的结构。时间 O(n)，空间 O(h)。"
