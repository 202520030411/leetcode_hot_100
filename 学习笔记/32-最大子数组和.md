# 32 最大子数组和（Maximum Subarray）· Kadane

> 动态规划 · 中等 · **极高频** · https://leetcode.cn/problems/maximum-subarray/
> 🎞 https://claude.ai/artifact/CFSZTpkAA5pDorGyf2PwgG

## 核心思路一句话

**`cur = max(x, cur + x)`：前面的累积是负担就甩掉，从自己重新开一段；另开一个 `best` 全局打擂台。**

## 题目

| | |
|---|---|
| 给你 | 整数数组，**可能有负数** |
| 返回 | **和最大的那个连续子数组**的和 |

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
下标:    0  1   2  3   4  5  6   7  8

试几段连续的：
  [4]                  → 4
  [4,-1]               → 3
  [4,-1,2]             → 5
  [4,-1,2,1]           → 6     ★ 最大（下标 3..6）
  [4,-1,2,1,-5]        → 1     加上 -5 反而变小
  整个数组             → 1

输出: 6
```

**⚠ `[4, 2, 1]` 不算** —— 跳过了 `-1`，不是连续的一段。

**全负数的情况（面试常用来坑人）：**

```
nums = [-3, -1, -2]
所有候选: -3 ｜ -1 ｜ -2 ｜ -4 ｜ -3 ｜ -6
输出: -1        ← 必须选一段（不能选空），所以是「最不亏的那个」
```

## 思路：每到一个元素，问「要不要接着前面」

**`cur` 的定义：以当前元素结尾的最大子数组和。**（「以 i 结尾」这个限定是关键）

```
① 接着前面那段  →  cur + x
② 不要前面了，从我自己重新开一段  →  x

cur = max(x, cur + x)
```

**什么时候该重新开始？** 当前面的 `cur` 是**负数**的时候 —— 带着它只会拖累。

## ★★ 和前两题最大的区别：答案不是最后一格

```
爬楼梯 / 打家劫舍:   答案 = dp[n-1]          （最后一格）
最大子数组和:        答案 = max(所有 cur)     ★ 全局打擂台
```

> **为什么？** 因为 `cur` 的定义是「**以 i 结尾**」，而最大的那段**不一定在最后一个元素结束**。
> 上面的例子里最大段是下标 3..6，第 7、8 个元素反而把它拖低了。

**所以要额外一个 `best` 全程记录见过的最大值。**

## 代码

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur = best = nums[0]              # ★ 用 nums[0] 初始化，不是 0
        for x in nums[1:]:
            cur = max(x, cur + x)         # 接着前面，还是从我重新开始
            best = max(best, cur)         # 全局打擂台
        return best
# 时间 O(n)，空间 O(1)
```

**两个变量各管一件事：**
- **`cur`** = 以当前元素结尾的最大和（会随时「重新开始」）
- **`best`** = 全程见过的最大值（只增不减）

## ★ 最经典的坑：初始值不能写 0

```
nums = [-3, -1, -2]
初始化成 0       → 返回 0   ❌（0 不对应任何一段子数组）
初始化成 nums[0] → 返回 -1  ✅
```

## 这个算法的名字

**Kadane 算法**。面试里说出名字是个小加分，但更重要的是能讲清「甩掉负担」这个推理。

## 复杂度

时间 **O(n)**，空间 **O(1)**。

## 面试怎么说

"设 `cur` 为以当前元素结尾的最大子数组和。每到一个元素，要么接上前面那段，要么从它自己重新开始，取大的：`cur = max(x, cur + x)`。因为最大的那段不一定在末尾结束，所以还要一个 `best` 全程打擂台。时间 O(n)，空间 O(1)。关键细节是初始值要用 `nums[0]` 而不是 0，否则全负数的数组会错误地返回 0。这个算法叫 Kadane 算法。"
