# 35 子集（Subsets）· 回溯模板

> 回溯 · 中等 · **回溯入门** · https://leetcode.cn/problems/subsets/
> 🎞 https://claude.ai/artifact/SCVoTLdxBDUcdkEp8RKRYH

## ★★ 回溯模板（8 道回溯题共用这一个）

```python
def backtrack(当前状态):
    if 到达终点:
        记录答案
        return
    for 每个可能的选择:
        做选择              ← 往前走一步
        backtrack(新状态)    ← 递归深入
        撤销选择            ← ★ 退回来，换下一个选择
```

> **「撤销选择」是回溯的名字来源** —— 走完一条路要退回岔路口，才能去走另一条。
> **DP 是「填表算答案」，回溯是「把所有可能性一个个走出来」。**

## 题目

| | |
|---|---|
| 给你 | 整数数组 `nums`，元素**互不相同** |
| 返回 | **所有可能的子集**（含空集和它自己），顺序无所谓 |

```
nums = [1, 2, 3]

全部子集（共 8 个 = 2³）：
   []  [1]  [2]  [3]  [1,2]  [1,3]  [2,3]  [1,2,3]

输出: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

**为什么正好 8 个？** 每个元素都有「选」「不选」两种可能 → `2×2×2 = 2³`。

## 思路：每个元素问一次「选不选」

**和打家劫舍是同一个决策结构**（每家「偷/不偷」），区别是：

```
打家劫舍：只要最优的那一个结果   →  DP，用 max 合并
子集：    要【全部】可能的结果   →  回溯，一条条走出来
```

**决策树：**

```
                        []
             不选1 ╱            ╲ 选1
                 []              [1]
        不选2 ╱    ╲ 选2    不选2 ╱  ╲ 选2
            []     [2]          [1]   [1,2]
       不选3╱ ╲选3  ╱ ╲        ╱ ╲     ╱ ╲
         [] [3] [2] [2,3]   [1] [1,3] [1,2] [1,2,3]
          └───────── 8 个叶子 = 8 个子集 ─────────┘
```

## 代码

```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = []
        path = []                          # 当前正在构建的子集

        def backtrack(i):
            if i == len(nums):             # 所有元素都问过了
                res.append(path[:])        # ★ 必须拷贝！
                return
            backtrack(i + 1)               # 选择一：不选 nums[i]
            path.append(nums[i])           # 选择二：选 —— 做选择
            backtrack(i + 1)               #            递归
            path.pop()                     #            ★ 撤销选择

        backtrack(0)
        return res
# 时间 O(n × 2^n)，空间 O(n)
```

## ★★ 两个必踩的坑

**① `res.append(path[:])` 的 `[:]` 不能省** —— 回溯最经典的 bug：

```
正确 res.append(path[:])  →  [[], [3], [2], [2,3], [1], [1,3], [1,2], [1,2,3]]
错误 res.append(path)     →  [[], [], [], [], [], [], [], []]    ← 8 个空列表
```

**为什么？** 「list 变量存的是标签不是箱子」（移动零那题）。`path` 全程只有**一个** list，不停被 append/pop 修改。直接放进去，`res` 里 8 个位置全指向**同一个箱子**，而那个箱子最后被 pop 空了。

```python
path[:]        # 切片 = 复制一份新 list
list(path)     # 同样效果
path.copy()    # 同样效果
```

**② `path.pop()` 撤销不能漏** —— 漏了 `path` 只增不减，后面所有分支都带着前面选过的元素。

```
做选择:  path.append(nums[i])
递归:    backtrack(i + 1)
撤销:    path.pop()              ← 这三行必须配对，是回溯的心跳
```

## 复杂度

时间 **O(n × 2^n)**（2^n 个子集，每个拷贝 O(n)），空间 **O(n)**（递归栈）。

## 面试怎么说

"用回溯枚举所有可能。对每个元素做「选」或「不选」两个分支，递归到底（所有元素都决定完）就把当前路径记进结果。关键三件事：记录答案时必须拷贝 `path[:]`，否则所有结果指向同一个列表；`append` 之后必须配对 `pop` 撤销选择；终止条件是下标走到数组末尾。时间 O(n·2^n)，空间 O(n)。"
