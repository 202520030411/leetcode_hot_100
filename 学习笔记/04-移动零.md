# 04 移动零（Move Zeroes）

> 双指针 · 简单 · https://leetcode.cn/problems/move-zeroes/
> **★ 我一次通过、零 bug 的第一题**

## 核心思路一句话

**`fast` 逐个读，遇到非零就写到 `slow` 位置并让 `slow` 前进；扫完后从 `slow` 到末尾全填 0。**

## 关键洞察：新数组就在原数组的前半段

最直接的想法是"把非零的挑出来放进新数组，后面补 0"。
原地版只改一件事：**别放进新数组，直接写回 `nums` 自己的前面。**

**为什么不会覆盖还没读的数据？**
每读一个才可能写一个，**写的次数必然 ≤ 读的次数**，所以 `slow` 永远追不上 `fast`。

## 关键洞察：slow 一物二用

> **`slow` 既是"下一个非零元素该写到哪儿"，也正好等于"已经找到几个非零元素"。**

所以补 0 直接从下标 `slow` 补到末尾，不用另外算。
这也是为什么 `slow` **只有真写了才 `+= 1`** —— 跟着 `fast` 无脑走就退化成同一个变量了。

## 执行过程（`[0,1,0,3,12]`）

```
fast=0  nums[0]=0   跳过                    [0,1,0,3,12]   slow=0
fast=1  nums[1]=1   nums[0]=1, slow→1       [1,1,0,3,12]   slow=1
fast=2  nums[2]=0   跳过                    [1,1,0,3,12]   slow=1
fast=3  nums[3]=3   nums[1]=3, slow→2       [1,3,0,3,12]   slow=2
fast=4  nums[4]=12  nums[2]=12, slow→3      [1,3,12,3,12]  slow=3

[ 1,  3, 12 | 3, 12 ]    从 slow=3 开始补 0  →  [1,3,12,0,0]
 └─ 答案 ─┘ └─垃圾─┘
```

## 必须记住的 Python 坑："原地"是什么意思

```python
def bad(nums):
    nums = [1, 3, 12, 0, 0]    # 外面完全没变！
def good(nums):
    nums[0] = 999              # 外面变了
```

**list 变量存的不是 list 本身，是"那个 list 放在哪儿"的一张标签：**

```
nums[0] = 999   →  打开箱子改里面        →  外面看到同一个箱子，变了 ✅
nums = [...]    →  把标签撕了贴到新箱子  →  老箱子没人动，白写 ❌
```

> **原地题只能用"改内容"的操作**：`nums[i] = x`、`.append()`、`.sort()`、`.reverse()`。
> 一旦写了 `nums = 什么`，这个函数就白写了。
> 真要整体替换内容：`nums[:] = [...]`（多个 `[:]`，意思是"换箱子里的东西"）。

## 正确代码（我写的版本，两趟）

```python
from typing import List

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        for k in range(slow, len(nums)):
            nums[k] = 0
        # 不用 return
```

**面试里更漂亮的一趟版（交换）：**

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]   # a,b = b,a 交换
                slow += 1
```

交换把 `slow` 位置上那个 0 顺手甩到后面，补 0 在搬运过程中自动完成。

## 复杂度

时间 **O(n)**，空间 **O(1)**（O(1) 空间正是"原地"的体现）。

## 面试怎么说

"快慢双指针。`fast` 负责扫描，`slow` 标记下一个非零元素该写的位置。
因为写的次数不会超过读的次数，`slow <= fast` 恒成立，所以就地覆盖是安全的。
扫完一趟后 `slow` 就是非零元素个数，剩下的位置填 0。时间 O(n)，空间 O(1)。"
