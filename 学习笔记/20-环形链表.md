# 20 环形链表（Linked List Cycle）

> 链表 · 简单 · **快慢指针代表题** · https://leetcode.cn/problems/linked-list-cycle/
> 🎞 https://claude.ai/artifact/D1AZ9iuFuL8YMj24aCJq9P

## 核心思路一句话

**慢指针走 1 步、快指针走 2 步。有环必相遇（差距每轮减 1），无环快指针先到 `None`。**

## 题目

| | |
|---|---|
| 给你 | 链表头节点 `head` |
| 返回 | `True` / `False`：**有没有环** |

```
无环:  3 → 2 → 0 → -4 → None       走 4 步到头
有环:  3 → 2 → 0 → -4
            ↑         │
            └─────────┘            -4 的 next 指回 2，永远走不到 None
```

## 解法一：朴素（先说这个，体现思考过程）

```python
seen = set()
cur = head
while cur:
    if cur in seen:        # 第二次见到这个节点 → 绕回来了
        return True
    seen.add(cur)
    cur = cur.next
return False
# 时间 O(n)，空间 O(n)
```

## ★★ 节点 ≠ 值（这题最重要的概念）

**`set` 里存的必须是节点对象，不是 `cur.val`。**

```
两个不同的盒子可以装相同的数字，但它们是两个不同的盒子。
记录「值」   = 记录名字    →  同名的人会被当成同一个  ❌
记录「节点」 = 记录身份证  →  同名也能分清            ✅
```

**实测反例：**

```
链表 1 → 1 → 1 → None（三个不同节点，无环）
  记录【值】 : True  ❌ 误判成有环（第二个 1 的值早就见过了）
  记录【节点】: False ✅

a == b ?  False   （两个不同盒子，哪怕值一样也不相等）
a == a ?  True    （同一个盒子才相等）
```

Python 里 `cur in seen` 比的是「是不是同一个对象」（ListNode 没定义值相等规则，默认按身份比）。

## 解法二：快慢指针（面试要的，空间 O(1)）

```python
class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        slow = fast = head
        while fast and fast.next:        # ★ 两个条件都要
            slow = slow.next             # 走 1 步
            fast = fast.next.next        # 走 2 步
            if slow == fast:
                return True
        return False
```

## ★ 三个关键细节

**① 为什么有环一定会相遇？**（必问）

> 两个指针都进环后，设相差 k 步。每轮快的走 2、慢的走 1 → **差距每轮正好缩小 1**：k → k-1 → … → 0。因为每轮只减 1，不可能跳过 0，所以必然重合。

**② 为什么快指针走 2 步，走 3 步行不行？**（高频追问）

> 走 3 步差距每轮减 2，可能从 1 直接跳到 -1，**错过相遇点**。走 2 步保证差距每轮只减 1，必然命中 0。

**③ `while fast and fast.next` 两个条件都要。**
fast 要走两步，必须确认「当前这个」和「下一个」都存在，否则 `fast.next.next` 会在 `None` 上取 next 直接崩。**这是本题最容易错的地方。**

## 复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| set 记录节点 | O(n) | O(n) |
| 快慢指针 | O(n) | **O(1)** ← 优势在这 |

## 面试怎么说

"朴素做法是用 set 记录访问过的**节点**（不是值，值可能重复），O(n) 时间 O(n) 空间。更优的是快慢指针：slow 每次 1 步、fast 每次 2 步。无环时 fast 先到 None；有环时两者都进环后差距每轮减 1，必然相遇。时间 O(n)，**空间 O(1)**。循环条件要写 `while fast and fast.next`，因为 fast 要走两步。"
