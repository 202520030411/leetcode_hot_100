# 21 合并两个有序链表（Merge Two Sorted Lists）

> 链表 · 简单 · **dummy 节点代表题** · https://leetcode.cn/problems/merge-two-sorted-lists/
> 🎞 https://claude.ai/artifact/PeNXd2seJH6MudburZoayK

## 核心思路一句话

**两边各看第一个，谁小摘谁接到结果后面；一边空了就把另一边剩下的整条挂上。用 dummy 节点省掉头节点特判。**

## 题目

| | |
|---|---|
| 给你 | 两条各自**升序**的链表 `l1`、`l2` |
| 返回 | 合并后仍然升序的链表头 |

```
l1:  1 → 2 → 4
l2:  1 → 3 → 4
合并: 1 → 1 → 2 → 3 → 4 → 4
```

**过程（就是你的直觉）：**

```
l1: [1] 2 4    l2: [1] 3 4     1 <= 1，摘 l1 的 1
l1: 1 [2] 4    l2: [1] 3 4     1 < 2， 摘 l2 的 1
l1: 1 [2] 4    l2: 1 [3] 4     2 < 3， 摘 l1 的 2
l1: 1 2 [4]    l2: 1 [3] 4     3 < 4， 摘 l2 的 3
l1: 1 2 [4]    l2: 1 3 [4]     4 <= 4，摘 l1 的 4
l1: 空         l2: 1 3 [4]     l1 空了 → 把 l2 剩下的 [4] 整条挂上
```

## ★ 新套路：dummy（哑节点）

**问题**：结果链一开始是空的，你得先确定「第一个节点是谁」才能开始接 —— 这会让代码分成「第一次接」和「后面接」两套逻辑。

**解法：先造一个假节点当桩，所有真节点都接在它后面，最后 `return dummy.next` 跳过它。**

```
dummy → (空)
dummy → 1
dummy → 1 → 1
...
dummy → 1 → 1 → 2 → 3 → 4 → 4
  ↑ return dummy.next 跳过假节点
```

> **dummy 的唯一作用：省掉「头节点要特殊处理」。**
> 凡是题目要「构造一条新链」或「可能删掉头节点」，先来一个 dummy。用得极多。

**另外要一个 `tail` 指针跟着走**，记住结果链的最后一个在哪。

## 代码

```python
class Solution:
    def mergeTwoLists(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)         # 假节点
        tail = dummy                # 结果链的尾巴
        while l1 and l2:
            if l1.val <= l2.val:
                tail.next = l1
                l1 = l1.next
            else:
                tail.next = l2
                l2 = l2.next
            tail = tail.next
        tail.next = l1 or l2        # ★ 剩下的整条挂上
        return dummy.next           # 跳过假节点
```

## ★ 三个关键细节

**① `tail.next = l1 or l2`** —— 一边空了之后，**另一边剩下的整条本来就有序**，直接挂上去，不用逐个比（已经没东西跟它比了）。`l1 or l2` = 「l1 非空取 l1，否则取 l2」。

**② `l1.val <= l2.val` 用 `<=` 而不是 `<`** —— 值相等时摘 l1 的，保持「相同值里 l1 的在前」，这叫**稳定**。两种都能过，但提一句是加分点。

**③ 空链自动处理** —— `l1` 是空的时候 `while` 一轮都不进，直接把 `l2` 整条挂上。**dummy 让这种情况不需要特判。**

## 复杂度

时间 **O(m+n)**（每个节点看一次），空间 **O(1)**（只重新连指针，没有新建节点）。

## 面试怎么说

"用一个 dummy 哑节点当结果链的桩，`tail` 指针跟着结果链的尾巴。每轮比较 `l1.val` 和 `l2.val`，把小的那个接到 `tail.next` 后面，对应的指针往后走一步。一边走完之后，把另一边剩下的整条直接挂上去（它本来就有序）。最后返回 `dummy.next`。时间 O(m+n)，空间 O(1)。dummy 的作用是省掉「结果链还空着」这种头节点特判。"
