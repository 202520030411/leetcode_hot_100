# 02 字母异位词分组（Group Anagrams）

> 哈希 · 中等 · https://leetcode.cn/problems/group-anagrams/

## 核心思路一句话

**给每个单词算一个"指纹"，指纹相同的就是同一组；用 dict 把指纹当键、该组单词的 list 当值。**

## 关键洞察

需要的指纹必须满足：**同组的词算出来完全一样，不同组的一定不同。**

把单词的字母**排序**就是这样的指纹 —— 排序抹掉了"顺序"这个差异，只留下"用了哪些字母、各几个"：

```
"eat" → "aet"    "tea" → "aet"    "ate" → "aet"     同组
"tan" → "ant"    "nat" → "ant"                      同组
"bat" → "abt"                                        单独一组
```

dict 长这样：
```python
{"aet": ["eat","tea","ate"], "ant": ["tan","nat"], "abt": ["bat"]}
```

## 我踩过的坑

| 我写的 | 正确 | 后果 |
|---|---|---|
| `return groups` | `return list(groups.values())` | **不报错但答案错**：交出去的是整本 dict，判题器不认识我自己造的键 |

**另一个必须注意的点（我当时绕过去了，但很容易撞）：**
`sorted("tan")` 返回的是 **list** `['a','n','t']`，**不是字符串**。
直接拿它当 dict 的键 → `TypeError: unhashable type: 'list'`。
必须 `"".join(sorted(word))` 粘回字符串。

> 见到 `unhashable type: 'list'`，条件反射：**我把 list 塞进 dict 的键或 set 了，得转成 tuple 或字符串。**

## 正确代码

```python
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = {}                              # 指纹 -> 该组的单词 list
        for word in strs:
            key = "".join(sorted(word))          # 排序抹掉顺序差异
            if key not in groups:
                groups[key] = []                 # 新组，先开个空 list
            groups[key].append(word)
        return list(groups.values())
```

**更短的写法（用 defaultdict 省掉 if）：**

```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)               # 查不到的键，自动给一个空 list
        for word in strs:
            groups["".join(sorted(word))].append(word)
        return list(groups.values())
```

## 复杂度

n 个单词、每个最长 L 个字母：时间 **O(n · L log L)**（排序），空间 **O(n · L)**。

## 面试怎么说

"用哈希表分组，键是这个词的规范形式。我先用排序后的字符串当键，O(n·L log L)。
如果 L 比较大，可以改用 26 位字母计数代替排序，键换成 `tuple(counts)`，把 log L 去掉，变成 O(n·L)。"

**26 位计数版的关键代码：**

```python
counts = [0] * 26                        # 26 个 0
for ch in word:
    counts[ord(ch) - ord('a')] += 1      # 'a'→0 位, 'b'→1 位 ...
key = tuple(counts)                      # list 不能当键，转 tuple
```
