# 23 二叉树的最大深度（Maximum Depth of Binary Tree）

> 二叉树 · 简单 · **递归入门** · https://leetcode.cn/problems/maximum-depth-of-binary-tree/
> 🎞 https://claude.ai/artifact/JVURVtcAU8S4kVGjGfuZVa

## 核心思路一句话

**空树深度 0；否则 `1 + max(左子树深度, 右子树深度)`。**

## 题目

| | |
|---|---|
| 给你 | 二叉树根节点 `root` |
| 返回 | 从根到最远叶子的路径上**有几个节点** |

```
        3            深度 = 3
       / \           （3 → 20 → 15 这条最长，3 个节点）
      9   20
         /  \
        15   7

空树 → 0        只有根 → 1
```

## 树的基础

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left      # 左孩子（没有就是 None）
        self.right = right    # 右孩子
```

**树就是「分叉的链表」** —— 链表每个节点一个 `next`，树每个节点两个（`left` / `right`）。
LeetCode 的输入 `[3,9,20,null,null,15,7]` 是「一层一层从左到右」列出来的，`null` 表示空位。

## ★★ 递归三步心法（所有树题通用）

```
① 信任递归：假设这个函数对更小的子树一定能给出正确答案
② 想清楚：拿到子树的答案后，我怎么拼出自己的答案
③ 写出最小情况（空节点）—— 这是递归的刹车，没有它会无限递归
```

**套到这题：**

```
我这棵树的深度 = 1（我自己这一层）+ 两个孩子里更深的那个的深度
```

## 代码（三行）

```python
class Solution:
    def maxDepth(self, root: TreeNode) -> int:
        if not root:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

## ★ 三个关键细节（面试必问）

**① 终止条件是「走到空节点」，不是「叶子节点」。**

```python
if not root:      # ← root 本身是 None
    return 0
```

**叶子不是终止条件** —— 叶子仍然会递归调用它的两个**空孩子**，各返回 0，然后算出 `1 + max(0,0) = 1`。
**所以不需要写 `if not root.left and not root.right: return 1`，那是多余的。**

没有终止条件会 `AttributeError`（在 None 上取 .left）或 `RecursionError`。

**② 为什么用 `max` 不是 `min` 或相加？** 深度的定义是「最远那条路」，取决于更深的那一边。

**③ 空间复杂度 O(h)，最坏 O(n)** ← 这题唯一容易答错的

```
递归的空间开销 = 调用栈的高度 = 树高 h

树平衡（左右差不多）  →  h ≈ log n  →  空间 O(log n)
树退化成一条链        →  h = n      →  空间 O(n)
```

**标准答法：「空间 O(h)，h 是树高；最坏树退化成链表是 O(n)」。** 只说 O(log n) 是错的。

## 复杂度

时间 **O(n)**（每个节点访问一次），空间 **O(h)**，最坏 **O(n)**。

## 面试怎么说

"递归。终止条件是节点为空返回 0；否则返回 `1 + max(左子树深度, 右子树深度)`，用 max 是因为深度取决于更深的那一边。时间 O(n)，每个节点访问一次；空间 O(h)，h 是树高，来自递归调用栈，最坏树退化成链表是 O(n)。注意终止条件是空节点而不是叶子，叶子会自然地通过两个空孩子算出 1。"
