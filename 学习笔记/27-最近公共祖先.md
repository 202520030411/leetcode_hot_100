# 27 二叉树的最近公共祖先（Lowest Common Ancestor）

> 二叉树 · 中等 · **树里最经典的难题** · https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/

## 核心思路一句话

**后序递归。自己是 p/q 就返回自己；左右子树都返回了非空 → 自己就是答案；只有一边非空就把它往上传。**

## 题目

| | |
|---|---|
| 给你 | 二叉树 `root`，和树里的两个节点 `p`、`q` |
| 返回 | 「最靠下的那个同时是它们俩祖先的节点」 |

```
        3
       / \
      5   1
     / \  / \
    6  2 0   8
      / \
     7   4

p=5, q=1  →  3      只有根同时是它俩的祖先
p=5, q=4  →  5      ★ 一个节点可以是自己的祖先！4 在 5 的子树里
p=7, q=4  →  2
p=6, q=4  →  5
```

> **「祖先」包括自己** —— 这是题目明说的，也是第二个例子的关键。

## ★★ 思路：让左右子树各自汇报「你那边有没有 p 或 q」

```
① 我自己就是 p 或 q      →  直接汇报「我这儿有」（不用往下找了）
② 左边有、右边也有       →  ★ 我就是答案
③ 只有一边有            →  把那边的汇报往上传
④ 两边都没有            →  汇报「没有」
```

**为什么「两边都有」就是答案？**

> p 和 q 分别在我的左右两个子树里，**任何比我更靠下的节点都只能装下其中一个** —— 所以我是最靠下的那个公共祖先。

## 代码

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if not root or root == p or root == q:
            return root                      # ① 空 或 自己就是目标 → 原样返回
        left = self.lowestCommonAncestor(root.left, p, q)    # 问左边
        right = self.lowestCommonAncestor(root.right, p, q)  # 问右边
        if left and right:
            return root                      # ② 两边都有 → 我是答案
        return left or right                  # ③④ 一边有就传上去，都没有传 None
```

## ★ 三个关键细节

**① `root == p` 比的是节点不是值** —— 题目保证 p、q 一定存在于树中。

**② `return left or right` 一行同时处理了③和④** —— 一边非空就返回那边；两边都是 None 就返回 None。

**③ 这是后序结构** —— 必须先拿到左右子树的汇报，才能判断自己是不是答案。
对比翻转二叉树（不依赖孩子结果，前序后序都行）。

## 复杂度

时间 **O(n)**（每个节点访问一次），空间 **O(h)**。

## 面试怎么说

"后序递归。对每个节点，先递归问左右子树有没有找到 p 或 q。如果节点自己就是 p 或 q 就直接返回它；如果左右子树各返回了非空，说明 p 和 q 分别在两侧，那当前节点就是最近公共祖先；如果只有一侧非空就把它往上传。时间 O(n)，空间 O(h)。关键是『两边都找到』这个条件 —— 因为更靠下的节点只能装下其中一个。"
