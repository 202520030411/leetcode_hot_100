# 01 两数之和（Two Sum）

> 哈希 · 简单 · https://leetcode.cn/problems/two-sum/

## 核心思路一句话

**边走边把"见过的数 → 它的下标"存进 dict，每到一个数就问一次"我缺的那个数之前出现过吗"。**

## 关键洞察

暴力解慢在哪：对每个 `nums[i]`，要找的其实是 `target - nums[i]` 这个**确定的数**，但用"从头翻到尾"这种最慢的方式去找。

> **"某个东西在不在" → 别用循环翻，用哈希。**
> 查 `key in dict` 不管表里有 3 对还是 300 万对，耗时一样。

**键值怎么定：拿着什么去查，什么当键；想得到什么，什么当值。**
这里拿着数字去查（`target - num`），想得到下标 → 键=数字，值=下标。

## 我踩过的坑

| 我写的 | 正确 | 后果 |
|---|---|---|
| `for j in range(i, n)` | `range(i + 1, n)` | **不报错但答案错**：`[3,2,4]` 返回 `[0,0]`，因为 `nums[0]+nums[0]=6` |
| `traget` | `target` | `NameError` |
| `return none` | `return []` | Python 的空值是大写 `None`；而且签名是 `-> List[int]`，该返回 list |
| `return none` 缩进 9 格 | 缩进 8 格 | `IndentationError: unindent does not match any outer indentation level` |
| `seen.add((num, i))` | `seen[num] = i` | `AttributeError: 'dict' object has no attribute 'add'`。`.add()` 是 set 的，dict 用 `d[k] = v` |
| `return seen[complem]` | `return [seen[complem], i]` | **不报错但答案错**：只返回了一个下标，返回 `0` 而不是 `[0,1]` |

**最重要的一条：先查后存，顺序不能反。**
若先存后查，`nums=[3,3], target=6` 时 `i=0` 存进 `{3:0}`，紧接着查到自己，返回 `[0,0]`。
我当时写对了，要保持。

## 正确代码

```python
from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}                                # 数字 -> 下标
        for i, num in enumerate(nums):
            complem = target - num               # 我缺的那个数（补数）
            if complem in seen:                  # 先查：之前见过吗？O(1)
                return [seen[complem], i]
            seen[num] = i                        # 后存：把自己记下来
        return []
```

执行过程（`nums=[2,7,11,15], target=9`）：

```
i=0  num=2   complem=7   7 in {}?      否  →  seen = {2: 0}
i=1  num=7   complem=2   2 in {2:0}?   是  →  return [0, 1]
```

## 复杂度

| | 暴力 | 哈希 |
|---|---|---|
| 时间 | O(n²) | **O(n)** |
| 空间 | O(1) | **O(n)** |

## 面试怎么说

"暴力是两层循环 O(n²)。优化点在于：内层其实是在找一个确定的值 `target - nums[i]`，这个查找可以用哈希表降到 O(1)。所以一趟遍历，边查边存，时间 O(n)，代价是 O(n) 额外空间 —— 用空间换时间。"
