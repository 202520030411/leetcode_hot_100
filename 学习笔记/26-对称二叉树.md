# 26 对称二叉树（Symmetric Tree）

> 二叉树 · 简单 · **交叉配对** · https://leetcode.cn/problems/symmetric-tree/
> 🎞 https://claude.ai/artifact/Wb2YsA3An2yhE7PrXFwLSg

## 核心思路一句话

**写一个收【两个】节点的辅助函数，交叉配对递归：`a.left ↔ b.right`、`a.right ↔ b.left`。**

## 题目

| | |
|---|---|
| 给你 | 二叉树根节点 `root` |
| 返回 | `True` / `False`：这棵树是否**左右镜像对称** |

```
      1                       1
    /   \                   /   \
   2     2                 2     2
  / \   / \                 \     \
 3   4 4   3                 3     3
   对称 ✅                  不对称 ❌（值全对，但结构不镜像）
```

**⚠ 不是「左子树等于右子树」，是「左子树和右子树互为镜像」。**

## ★★ 核心：单个指针不够，要同时比两个节点

```
比较 a 和 b 这一对时，往下要比的是：

        a             b
       / \           / \
      aL  aR       bL  bR

      a 的左  配  b 的右      （aL ↔ bR）
      a 的右  配  b 的左      （aR ↔ bL）
             ↑
        交叉配对，这就是「镜像」
```

> **如果写成 `aL ↔ bL`（同侧配对），那是在判断「两棵树相同」，不是「镜像」** —— 这是本题唯一的坑。

## 代码

```python
class Solution:
    def isSymmetric(self, root: TreeNode) -> bool:
        if not root:
            return True
        return self.check(root.left, root.right)     # 拿左右子树去比

    def check(self, a, b):
        if not a and not b:                 # ① 两边都空 → 这一对对称
            return True
        if not a or not b:                  # ② 一边空一边不空 → 不对称
            return False
        if a.val != b.val:                  # ③ 值不同 → 不对称
            return False
        return self.check(a.left, b.right) and self.check(a.right, b.left)
        #                 ↑ 交叉配对
```

## ★ 三个终止条件的顺序不能换

```
① 先判「都空」      → True
② 再判「一个空」    → False
③ 最后才敢访问 a.val
```

**顺序反了会在 `None` 上取 `.val` 崩掉。** 这又是你见过多次的「**先查边界，再查内容**」。

## 复杂度

时间 **O(n)**，空间 **O(h)**。

## 面试怎么说

"对称不是左右子树相等，而是互为镜像，所以需要同时比较两个节点。写一个辅助函数 `check(a, b)`：两边都空返回 True，一边空返回 False，值不等返回 False；否则递归比较 `a.left` 和 `b.right`、`a.right` 和 `b.left` —— **交叉配对**。三个终止条件的顺序不能换，否则会在 None 上取 val。时间 O(n)，空间 O(h)。"
