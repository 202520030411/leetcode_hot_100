# 05 盛最多水的容器（Container With Most Water）

> 双指针 · 中等 · https://leetcode.cn/problems/container-with-most-water/

## 核心思路一句话

**一左一右两个指针往中间夹，每轮算一次水量，然后把矮的那根往中间挪。**

## 唯一的公式

```
水量 = 宽 × 高 = (right - left) × min(height[left], height[right])
```

**高取两根里矮的那根** —— 水从矮的那边漏出去。

## 关键洞察：为什么移动矮的那根

**躲不掉的事实：无论移哪根，宽度都减 1。** 唯一的希望在高度上。

- **移动高的那根**：高度 = `min(矮的, 新的)` ≤ 矮的，**永远不可能变大**。宽变小 + 高不变 = 面积必然变小。**纯亏，零可能性。**
- **移动矮的那根**：新的那根可能更高，**高度有机会变大**。有赚的可能。

**面试要说的严谨版：**

> 矮的那根柱子（设为 `left`，高 1），它能配的柱子都在它右边。现在配的是最远的一根，**宽度已是它能拿到的最大值**；而它参与的任何桶，**高度都不可能超过它自己的高度 1**。
> 所以当前这个面积就是"以这根柱子为一端"的最大值，**这根柱子可以永久丢弃**。

每轮永久淘汰一根柱子 → 最多 n 轮 → **O(n)**。
双指针不是在枚举所有组合，而是**每一步安全地排除掉一批不可能更优的组合**。

## 我踩过的坑 ★ 下标 ≠ 值

```
height = [ 1,  8,  6,  2,  5,  4,  8,  3,  7]
下标:      0   1   2   3   4   5   6   7   8
           ↑
         left = 0          ← 位置编号
         height[left] = 1  ← 那根柱子的高度
```

| 我写的 | 它在做什么 | 正确 |
|---|---|---|
| `min(left, right)` | 比较**位置编号** 0 和 8，得到 0 | `min(height[left], height[right])` |
| `height[left] += 1` | 把第 0 根柱子**加高一格**（破坏输入！） | `left += 1`（指针右移） |
| `height[right] -= 1` | 把第 8 根柱子**削矮一格** | `right -= 1`（指针左移） |

后果是**死循环**（`left`/`right` 从不改变）**外加破坏输入数组**。

> **移动指针改的是 `left` / `right` 本身。`height` 在这题里是只读的，一个字都不该改。**

**自查方法**：写完 `while` 后，在循环体里找 `left`、`right` 这两个名字**单独出现并被赋值**的地方（不是 `height[left]` 这种带方括号的）。找不到 → 死循环。

## 正确代码

```python
from typing import List

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        best = 0
        while left < right:                    # 注意是 < 不是 <=，相遇就围不成桶
            water = (right - left) * min(height[left], height[right])
            best = max(best, water)
            if height[left] < height[right]:
                left += 1                      # 左边矮，丢弃左边
            else:
                right -= 1                     # 右边矮或一样高，丢弃右边
        return best
```

`else` 那支包含"两根一样高"——此时两根都已榨干，移哪根都行。

## 复杂度

时间 **O(n)**，空间 **O(1)**。

## 副产品：看约束反推复杂度（很实用）

| n 的规模 | 允许的复杂度 | 对应做法 |
|---|---|---|
| n ≤ 20 | O(2ⁿ) | 暴力枚举、回溯 |
| n ≤ 2000 | O(n²) | 两层循环、DP |
| **n ≤ 10^5** | **O(n) / O(n log n)** | **双指针、哈希、排序** |
| n ≤ 10^9 | O(log n) | 二分查找、数学 |

判题机一秒约跑 10^7 ~ 10^8 次基本运算。
本题 n ≤ 10^5，O(n²) = 10^10 → 约 100 秒 → 必然 TLE。
**动手前先看约束，就知道该往哪个方向想。**
