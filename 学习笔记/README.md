### 模式 2：双指针

"指针"就是**一个存下标的普通变量**，Python 里没有真指针。

两种形态：
- **同向（快慢）**：都从左往右，速度不同 → 一边扫描一边就地整理数组
- **相向（对撞）**：一左一右往中间夹 → 有序数组找配对 / 从两端收缩求最优

为什么快：**两个下标各自只往一个方向走、绝不回头** → n + n → O(n)

|---|---|---|---|
| [04](./04-移动零.md) | 移动零 | 快慢 | **无（一次通过）** |
| [05](./05-盛最多水的容器.md) | 盛最多水的容器 | 相向 | 下标当成值、改数组当成移指针 → 死循环 |
| [06](./06-三数之和.md) | 三数之和 | 排序 + 相向 | ⚠️ **代码是 Claude 写的，欠一遍独立重写** |

### 模式 3：滑动窗口

**窗口 = 用 `left`/`right` 两个下标标出的一段连续区间。** 两个下标都只往右走、绝不回头 → O(n)
触发信号：**「子串 / 子数组 / 连续」+ 求最长/最短/恰好**（看到「子序列」则多半是 DP）

通用模板：**`for` 管扩张，`while` 管收缩，收缩完更新答案**

**两种形态：**

| 固定 | 宽度恒等于目标长度，整体平移，**不需要 while** | 08 字母异位词 |

### 模式 3.5：前缀和 + 哈希（滑窗用不了时的替代）

**数组有负数 → 窗口没有方向盘 → 滑窗和双指针都失效。** 改用前缀和：

```
任意一段的和 = prefix[j+1] - prefix[i]        （prefix 最前面补一个 0）
要找和为 k   →  prefix[i] = prefix[j+1] - k   →  哈希表查「这个值之前出现过几次」
```

### 模式 5：二分查找

**前提：数组有序。** 看中间那个，比一下，**另一半整个排除** → O(log n)。

**★ 核心不是背模板，是想清楚 `left`/`right` 的定义：**

```
left  的含义：它左边的元素全都 < target
right 的含义：它右边的元素全都 > target
      ↓
left 是一条分界线：左边全小 │ 右边全大
      ↓
二分不是在「找 target」，是在「把这条分界线逼出来」
```

触发信号：**「有序数组」/「请用 O(log n)」/「找第一个满足X的位置」/ n 到 10^9**

| # | 题 | 要点 | 我的 bug |
|---|---|---|---|
| [14](./14-搜索插入位置.md) | 搜索插入位置 | 闭区间三行：`len-1` / `<=` / `mid±1` | 无（理解了「定义决定边界」） |
| [15](./15-查找元素首末位置.md) | 查找元素首末位置 | **找到了也别停**，继续往一边压 → `lower_bound` | 无（三空全对） |
| [16](./16-搜索二维矩阵.md) | 搜索二维矩阵 | 矩阵＝拉直的有序数组，`row=mid//n` `col=mid%n` | — |
| [17](./17-旋转数组找最小.md) | 旋转数组找最小 | **B 套写法**：`while left < right` + `right = mid` | — |
| [18](./18-搜索旋转排序数组.md) | 搜索旋转排序数组 | 断崖只有一个 → **至少一半有序**，先判哪半再判 target | — |

**★ 二分有两套写法，按「mid 能不能排除」选：**

| | **A 套**（14/15/16） | **B 套**（17） |
|---|---|---|
| 用在 | 比较后 mid **确定不是**答案 | mid **可能就是**答案（找边界/极值） |
| 循环条件 | `while left <= right` | `while left < right` |
| 收缩 | 两边都 `±1` | `right = mid`（保留）/ `left = mid + 1` |
| 返回 | `left` 或 `-1` | `nums[left]` |

**二分的真正前提不是「全局有序」，而是「能根据 mid 判断答案在哪一半」** —— 旋转数组不全局有序，照样能二分。

**`lower_bound(x)` = 第一个 >= x 的位置。** 手写它能解决一大类题：
首位置 = `lower_bound(target)`，末位置 = `lower_bound(target+1) - 1`。

### 模式 6：链表

**链表＝一串盒子，每个装「值 + 下一个在哪」。** 只能顺着找（不能跳），但改指针是 O(1)。

> **铁律：改一个节点的 `next` 之前，先把原来的 `next` 存下来。**
> **节点 ≠ 值**：`set` / `==` 比的是「同一个盒子」，`[1,1,1]` 三个节点值一样但互不相等。

### 模式 7：二叉树（递归）

**树＝分叉的链表**（每个节点两个 next：`left` / `right`）。

**★ 递归三步心法：**

```
① 信任递归对更小的子树给出正确答案
② 想清楚拿到子树答案后怎么拼出自己的
③ 写出最小情况（空节点）—— 递归的刹车
```

### 模式 9：动态规划

**★ DP 四步固定流程（面试照着说）：**

```
① 定义 dp[i] 是什么        ← 面试官一定先问这个
② 看「最后一步」有哪几种可能

```

### 模式 11：回溯

**★ 模板（8 道回溯题共用）：**

```python
def backtrack(当前状态):
    if 到达终点:
        记录答案（★ 必须拷贝 path[:]）
        return
    for 每个选择:
        做选择
        backtrack(新状态)
        撤销选择          ← 回溯的心跳
```

|---|---|---|---|

| [36](./36-全排列.md) | 全排列 | 每位置「放哪个未用的」→ n! | 多一个 `used`，**和 path 配对撤销** |

## 看约束反推复杂度（动手前先看一眼）

| n 的规模 | 允许的复杂度 | 对应做法 |
|---|---|---|
| n ≤ 20 | O(2ⁿ) | 暴力枚举、回溯 |
| n ≤ 2000 | O(n²) | 两层循环、DP |
| n ≤ 10^5 | O(n) / O(n log n) | 双指针、哈希、排序 |
| n ≤ 10^9 | O(log n) | 二分查找、数学 |

判题机一秒约跑 10^7 ~ 10^8 次基本运算。
