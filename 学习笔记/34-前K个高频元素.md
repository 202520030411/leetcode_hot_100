# 34 前 K 个高频元素（Top K Frequent Elements）

> 堆 · 中等 · **Top K 模板** · https://leetcode.cn/problems/top-k-frequent-elements/

## 核心思路一句话

**先用 Counter 数次数，再维护一个只装 k 个的【小根堆】—— 堆顶是「前 k 名的守门员」。**

## 堆是什么：取出顺序由「值的大小」决定

```
栈   stack：后进先出     取出 = 最后放进去的
队列 queue：先进先出     取出 = 最先放进去的
堆   heap ：★ 最小先出    取出 = 桶里最小的那个（不管什么时候放的）
```

> **堆的用途只有一个：随时拿到「当前最小（或最大）的那个」，O(log n)。**

```python
import heapq

h = []
heapq.heappush(h, 5)       # 放进去         O(log n)
h[0]                        # 看一眼最小的   O(1)
heapq.heappop(h)            # 取出最小的     O(log n)
heapq.heapify(lst)          # 把现成 list 原地变成堆  O(n)
```

> **⚠ Python 的 `heapq` 只有小根堆（最小的在上面）。要最大的就把值取负存进去** —— 这是 Python 的标准技巧，面试要知道。

## 题目

| | |
|---|---|
| 给你 | 整数数组 `nums`、整数 `k` |
| 返回 | 出现次数**最多的前 k 个元素**（顺序无所谓） |

```
nums = [1,1,1,2,2,3],  k = 2

先数次数：  1 出现 3 次 ｜ 2 出现 2 次 ｜ 3 出现 1 次
按次数排名：1(3次) > 2(2次) > 3(1次)
取前 2 名 → [1, 2]

输出: [1, 2]
```

## ★ 为什么用「小根堆」找「最大的 k 个」

**这个点很反直觉但很关键：**

> **堆顶是堆里次数最少的那个 —— 它就是「前 k 名里的守门员」。**
> 新来的只要比守门员强，就把守门员踢出去。这样堆里永远维持着「目前见过的最强的 k 个」。

## 代码

```python
import heapq
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)                      # {1: 3, 2: 2, 3: 1}
        heap = []
        for num, freq in count.items():
            heapq.heappush(heap, (freq, num))      # ★ 元组，按 freq 排序
            if len(heap) > k:
                heapq.heappop(heap)                # 超过 k 个就踢掉次数最少的
        return [num for freq, num in heap]
# 时间 O(n log k)，空间 O(n)
```

## ★ 三个关键细节

**① `heappush(heap, (freq, num))` 塞的是元组。** 堆比较元组时**按第一个元素排**，所以 `freq` 必须放前面。放反了就变成按数值排序，答案全错。

**② 为什么 O(n log k) 比排序的 O(n log n) 好？** 堆里只有 k 个元素，每次操作是 `log k` 不是 `log n`。**当 k 远小于 n 时（一亿个数找前 10 个）优势巨大。**

**③ 一行版（面试可以先说这个，再给堆的版本）：**

```python
return [num for num, freq in Counter(nums).most_common(k)]
# Counter 自带方法，O(n log n)。面试官通常想看你手写堆。
```

## 追问「能不能 O(n)」

**能，用桶排序**：按出现次数当下标分桶（次数最多是 n），然后从高频桶往低频桶取 k 个。
知道有这个方案就行，面试里堆的版本够用。

## 面试怎么说

"先用哈希表统计每个元素的出现次数，然后维护一个大小为 k 的小根堆，按次数排序。堆顶是堆里次数最少的，相当于前 k 名的守门员 —— 每来一个新元素就 push 进去，如果堆超过 k 个就 pop 掉堆顶。最后堆里剩下的就是前 k 高频。时间 O(n log k)，比全排序的 O(n log n) 好，尤其当 k 远小于 n。注意 Python 的 heapq 是小根堆，找最大的若干个正好用它当守门员。还可以用桶排序做到 O(n)。"
