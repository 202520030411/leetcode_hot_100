# 18 搜索旋转排序数组（Search in Rotated Sorted Array）

> 二分查找 · 中等 · **二分最绕的一道** · https://leetcode.cn/problems/search-in-rotated-sorted-array/
> 🎞 https://claude.ai/artifact/CQX3CZYD1vtmfHQppDTXiu

## 核心思路一句话

**mid 把范围切两半，断崖只有一个，所以至少有一半完全有序 —— 先判断哪半有序，再用端点判断 target 在不在那半里。**

## 题目

| | |
|---|---|
| 给你 | 旋转后的升序数组（元素互不相同）、目标值 `target` |
| 返回 | `target` 的下标；不存在返回 `-1`。要 **O(log n)** |

```
nums = [4,5,6,7,0,1,2]
下标:   0 1 2 3 4 5 6

target = 0  →  4
target = 6  →  2
target = 3  →  -1
```

**「旋转」= 把前面一段整体搬到末尾：** `[0,1,2,4,5,6,7]` → `[4,5,6,7,0,1,2]`

## ★ 为什么普通二分会错（实测）

```
用普通二分找 1：
  第1轮: mid=3, nums[3]=7 > 1 → 「目标更小，去左半」→ right=2
  第2轮: mid=1, nums[1]=5 > 1 → 去左半 → right=0
  第3轮: mid=0, nums[0]=4 > 1 → 去左半 → right=-1
  返回 -1  ❌ 但 1 明明在下标 5！
```

**普通二分的推理「nums[mid] 比 target 大 ⟹ target 在左半」只在整体升序时成立。** 这里左半是 `[4,5,6,7]`，而 1 在右半 —— 因为**右半的值反而更小**。

## ★★ 核心洞察：至少有一半完全有序

**因为断崖只有一个。** mid 落在断崖某一侧，另一侧那半就不含断崖：

```
[4, 5, 6, 7, 0, 1, 2]        mid=3（值7）在断崖左边
 L        M        R          → 左半 [4,5,6,7] 有序 ✅，右半含断崖 ❌

[4, 5, 6, 7, 0, 1, 2]        mid=4（值0）在断崖右边
 L           M     R          → 右半 [0,1,2] 有序 ✅，左半含断崖 ❌
```

**怎么判断哪半有序：**

```python
if nums[left] <= nums[mid]:     # 左端 <= 中间 → 左半没跨断崖 → 有序
```

> 如果左半跨过断崖，`nums[left]`（在大段）一定**大于** `nums[mid]`（已掉到小段）。
> 用 `<=` 而不是 `<` 是为了处理 `left == mid`（左半只有一个元素，当然有序）。

**然后在有序那半里判断 target 在不在 —— 只需比两个端点。**

## 代码

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            if nums[left] <= nums[mid]:                    # 左半有序
                if nums[left] <= target < nums[mid]:       # target 在左半区间内
                    right = mid - 1
                else:
                    left = mid + 1
            else:                                           # 右半有序
                if nums[mid] < target <= nums[right]:      # target 在右半区间内
                    left = mid + 1
                else:
                    right = mid - 1
        return -1
```

## ★ 三个关键细节

**① `nums[left] <= nums[mid]` 用 `<=`** —— 处理 `left == mid` 的情况。

**② 两个区间的开闭不对称**（`[nums[left], nums[mid])` 和 `(nums[mid], nums[right]]`）—— 因为 `nums[mid]` 在循环开头已经比过、确定不等于 target，所以被排除在两个区间外。

**③ 这题回到 A 套写法（±1）。** 因为 `nums[mid] == target` 时直接 return，走到后面说明 mid 确定不是答案，可以放心排除。
对比第 17 题（找最小值）：mid 可能就是答案 → 必须用 B 套 `right = mid`。

**④ 连续比较 `nums[left] <= target < nums[mid]`** 是 Python 的写法，等价于 `nums[left] <= target and target < nums[mid]`。

## 复杂度

时间 **O(log n)**，空间 **O(1)**。

## 面试怎么说

"旋转数组由两段升序组成，断点只有一个，所以 mid 两侧至少一侧完全有序。我先用 `nums[left] <= nums[mid]` 判断左半是否有序，然后在有序的那一半里用两个端点判断 target 是否落在其中：落在就收缩到那一半，否则去另一半。每轮都砍掉一半，O(log n)。注意判断用 `<=` 处理 left==mid，而且两个区间的开闭不对称，因为 mid 已经单独比过了。"
